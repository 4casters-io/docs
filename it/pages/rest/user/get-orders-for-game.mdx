---
title: 'Ottieni gli ordini di un evento'
description: 'Elenca i tuoi ordini aperti e le scommesse abbinate su un singolo evento'
openapi: 'GET /user/getOrdersForGame'
---

Dato un id di evento 4casters, restituisce gli ordini aperti e le scommesse abbinate (non refertate) del chiamante per quell'evento. Le scommesse refertate non vengono restituite da questo endpoint — per quelle usa [Ottieni le giocate refertate](/it/pages/rest/user/get-graded-wagers).

## Richiesta {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>Id dell'evento 4casters.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Risposta {#response}

<ResponseField name="data.unmatched" type="array">
  Array di ordini aperti sull'evento, ordinati in modo crescente per ora di inizio dell'evento. Stessa forma di [Ottieni gli ordini non abbinati](/it/pages/rest/user/get-unmatched-orders).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Array di scommesse abbinate (non refertate) sull'evento. Stessa forma di [Ottieni le scommesse abbinate](/it/pages/rest/user/get-matched-bets).
</ResponseField>

### Esempio {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## Errori {#errors}

| Stato | Significato |
| ------ | ------- |
| `404`  | `gameID` mancante o non un id di evento valido. |
