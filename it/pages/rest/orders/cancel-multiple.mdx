---
title: 'Annullare più ordini'
description: 'Annulla un batch di ordini per id'
openapi: 'POST /session/cancelMultiple'
---

Annulla un batch di ordini per id. Il risultato è posizionale rispetto all'array `sessionIDs` in input e può contenere un misto di annullamenti riusciti e fallimenti per-ordine.

## Richiesta {#request}

`POST /session/cancelMultiple`

<ParamField body="sessionIDs" type="array" required>
  Array di id di ordini da annullare. Ogni id deve essere un `ObjectID` valido — se anche uno solo è malformato l'intera richiesta fallisce con `400`.
</ParamField>

<CodeGroup>
```bash curl
curl -X POST https://api.4casters.io/session/cancelMultiple \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionIDs": [
      "65b036dfb31407c2b6bc1cfe",
      "65b036e0b31407c2b6bc1d08"
    ]
  }'
```
</CodeGroup>

## Risposta {#response}

<ResponseField name="data" type="array">
  Risultati di annullamento per-ordine. Stessa forma di [Annullare un ordine](/it/pages/rest/orders/cancel-order#response). In caso di fallimento, le voci includono `{ success: false, reason: "..." }` (nessun campo `sessionID` per i rifiuti id-non-valido / non-trovato / non-tuo).
</ResponseField>

### Esempio {#example}

<CodeGroup>
```json JSON
{
  "data": [
    {
      "success": true,
      "sessionID": "65b036dfb31407c2b6bc1cfe",
      "odds": 125,
      "filled": 0,
      "offered": 0,
      "remaining": 100,
      "gameID": "65f0c3c24ef07d0008abc123"
    },
    { "success": false, "reason": "Not your order" }
  ]
}
```
</CodeGroup>

## Errori {#errors}

| Stato | Significato |
| ------ | ------- |
| `400`  | `sessionIDs` mancante o non un array, oppure un id malformato. |
