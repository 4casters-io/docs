---
title: 'Ottieni le commissioni di affiliazione'
description: 'Commissioni pagate a te dai giocatori che hai invitato'
openapi: 'GET /affiliate/getAffiliateCommission'
---

Restituisce le commissioni pagate al chiamante dai giocatori che ha invitato, raggruppate per nome utente del giocatore. Senza parametri, restituisce i guadagni di sempre; con `fromDate` / `toDate`, limita l'intervallo.

<Note>
A differenza della maggior parte degli endpoint, questo restituisce il risultato al **livello superiore** come `commissionPaid` (non sotto `data`).
</Note>

## Richiesta {#request}

`GET /affiliate/getAffiliateCommission`

<ParamField query="fromDate" type="string">
  Data di inizio (`MM-DD-YYYY`). Il valore predefinito è `08-02-2021`.
</ParamField>
<ParamField query="toDate" type="string">
  Data di fine (`MM-DD-YYYY`). Il valore predefinito è oggi.
</ParamField>

<CodeGroup>
```bash curl (intervallo di date)
curl "https://api.4casters.io/affiliate/getAffiliateCommission?fromDate=10-03-2022&toDate=10-10-2022" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (di sempre)
curl https://api.4casters.io/affiliate/getAffiliateCommission \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Risposta {#response}

<ResponseField name="commissionPaid" type="array">
  Ogni voce è un oggetto a chiave singola che mappa il nome utente di un giocatore sul totale delle commissioni pagate da quel giocatore nell'intervallo richiesto.
</ResponseField>

### Esempio {#example}

<CodeGroup>
```json JSON
{
  "commissionPaid": [
    { "alice":   124.50 },
    { "bob":      12.00 },
    { "charlie":  87.34 }
  ]
}
```
</CodeGroup>

## Errori {#errors}

| Stato | Significato |
| ------ | ------- |
| `400`  | `fromDate` non è interpretabile. |
