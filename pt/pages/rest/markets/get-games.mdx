---
title: 'Obter jogos'
description: 'Listar jogos ativos de uma liga'
openapi: 'GET /exchange/v2/getGames'
---

Devolve todos os jogos ativos de uma liga. A resposta **não** inclui o livro de ordens nem quaisquer preços — chame [Obter livro de ordens](/pt/pages/rest/markets/get-orderbook) para isso.

## Pedido {#request}

`GET /exchange/v2/getGames`

<ParamField query="league" type="string" required>
  Código de liga de [Obter ligas](/pt/pages/rest/markets/get-leagues). Use o valor especial `upcoming` para obter todos os jogos futuros em todas as ligas.
</ParamField>
<ParamField query="sport" type="string">
  Filtro de desporto opcional.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/v2/getGames?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data.games" type="array">
  <Expandable title="Game">
    <ResponseField name="id"             type="string">Id do jogo.</ResponseField>
    <ResponseField name="parentGameID"   type="string">Id do jogo pai, se este for um mercado filho (props, períodos alternativos).</ResponseField>
    <ResponseField name="cheapDataUID"   type="string">Identificador estável entre sistemas para o jogo (usado para correlação de linhas).</ResponseField>
    <ResponseField name="league"         type="string" />
    <ResponseField name="sport"          type="string" />
    <ResponseField name="start"          type="string">Hora de início em ISO 8601.</ResponseField>
    <ResponseField name="ended"          type="boolean" />
    <ResponseField name="live"           type="boolean" />
    <ResponseField name="featured"       type="boolean" />
    <ResponseField name="eventName"      type="string" />
    <ResponseField name="tournamentName" type="string" />
    <ResponseField name="periodName"     type="string">p. ex. `Full Time`, `1H`, `Set 1`.</ResponseField>
    <ResponseField name="isSpecials"     type="boolean">`true` para futuros e outros mercados especiais.</ResponseField>
    <ResponseField name="participants"   type="array">Array de dois elementos `[away, home]`. Cada participante tem `id`, `longName`, `shortName`, `homeAway`, `mainPitcher`, `rotationNumber`, `futuresSide`.</ResponseField>
  </Expandable>
</ResponseField>
