---
title: '获取单场订单簿'
description: '读取单场赛事的嵌套订单簿，以及子市场'
openapi: 'GET /exchange/getSingleOrderbook'
---

返回单场赛事的**嵌套**订单簿 — 让分和大小分是按盘口数字键控的对象，而不是扁平数组。同时返回任何子赛事（附加盘、分段盘）以及调用方在该联赛上自己挂单的 `orderSummary`。

若需要更简单的扁平形态，请优先使用 [获取订单簿](/zh/pages/rest/markets/get-orderbook)。

## 请求 {#request}

`GET /exchange/getSingleOrderbook`

<ParamField query="gameID" type="string" required>
  赛事 ID。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getSingleOrderbook?gameID=65b67450503180295ade9216" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.game" type="object">
  带嵌套订单簿字段的赛事对象。适用标准 `Game` 字段（见 [获取赛事](/zh/pages/rest/markets/get-games#response)），此外还有：

  <Expandable title="单场订单簿字段">
    <ResponseField name="awayMoneylines" type="array">客胜一侧的挂单单胜盘订单。按最优价格优先排序。</ResponseField>
    <ResponseField name="homeMoneylines" type="array">主胜一侧的挂单单胜盘订单。</ResponseField>
    <ResponseField name="awaySpreads"    type="object">以让分数为键的对象（例如 `"-3.5"`）。每个值为订单数组。</ResponseField>
    <ResponseField name="homeSpreads"    type="object">以让分数为键的对象。</ResponseField>
    <ResponseField name="over"           type="object">以大小分数为键的对象（例如 `"220.5"`）。每个值为订单数组。</ResponseField>
    <ResponseField name="under"          type="object" />
    <ResponseField name="homeMoneylines1x2" type="object">**仅足球。** 包含 `homeYes` / `homeNo` 数组的对象。</ResponseField>
    <ResponseField name="awayMoneylines1x2" type="object">**仅足球。** 包含 `awayYes` / `awayNo` 数组的对象。</ResponseField>
    <ResponseField name="draw1x2"           type="object">**仅足球。** 包含 `drawYes` / `drawNo` 数组的对象。</ResponseField>
    <ResponseField name="mainHomeSpread"  type="string">当前展示的主队主盘让分（共识盘口）。</ResponseField>
    <ResponseField name="mainAwaySpread"  type="number" />
    <ResponseField name="mainTotal"       type="string" />
    <ResponseField name="openInterest"    type="number" />
    <ResponseField name="matchedVolume"   type="number" />
  </Expandable>
</ResponseField>
<ResponseField name="data.orderSummary" type="array">
  调用方在整个联赛上自己的挂单（不限于本场赛事）。用于在 UI 中渲染「你的挂单」标记。
</ResponseField>
<ResponseField name="data.childGames" type="array">
  所请求赛事的子赛事（分段盘等）。形态与 `data.game` 相同。
</ResponseField>
<ResponseField name="data.propGames" type="array">
  与所请求赛事关联的附加盘赛事。
</ResponseField>
