---
title: '按 wager request ID 获取投注'
description: '查找由单次下单请求产生的全部投注'
openapi: 'GET /user/getBetByWagerRequestID'
---

查找与单个 `wagerRequestID` 关联的全部投注。`wagerRequestID` 由服务器为下单请求中的**每一笔**订单生成 — 用它把单次提交订单所产生的每一笔成交和挂单关联起来。

响应将结果分为三个桶：

- `unmatched` — 该请求中仍挂在订单簿上的未成交挂单。**此端点始终为空** — 若需要响应中包含未成交挂单，请改用 [按用户引用获取投注](/zh/pages/rest/user/get-bet-by-user-reference)。
- `matched`   — 该请求中已撮合（未结算）的投注。
- `graded`    — 该请求中已结算的投注，包含 `risk`、`win`、`fee` 和 `result`。

## 请求 {#request}

`GET /user/getBetByWagerRequestID`

<ParamField query="wagerRequestID" type="string" required>
  `/session/v3/place` 返回的 `wagerRequestID`（位于 `matched[].wagerRequestID` 或 `unmatched.wagerRequestID` 字段）。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getBetByWagerRequestID?wagerRequestID=65f69afec4c141f5ecc5dc0b" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.unmatched" type="array">空数组。</ResponseField>
<ResponseField name="data.matched" type="array">
  已撮合（未结算）投注 — 形态与 [获取已撮合投注](/zh/pages/rest/user/get-matched-bets#response) 相同。
</ResponseField>
<ResponseField name="data.graded" type="array">
  已结算投注 — 形态与 [获取已结算注单](/zh/pages/rest/user/get-graded-wagers#response) 相同。
</ResponseField>

## 错误 {#errors}

| 状态 | 含义 |
| ------ | ------- |
| `400`  | `wagerRequestID` 缺失或未知。 |
