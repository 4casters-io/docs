---
title: '获取单场赛事的订单'
description: '列出你在单场赛事上的未成交订单和已撮合投注'
openapi: 'GET /user/getOrdersForGame'
---

对于给定的 4casters 赛事 ID，返回调用方在该赛事上的未成交订单和已撮合（未结算）投注。此端点不返回已结算投注 — 请使用 [获取已结算注单](/zh/pages/rest/user/get-graded-wagers)。

## 请求 {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>4casters 赛事 ID。</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.unmatched" type="array">
  该赛事上的未成交订单数组，按开赛时间升序排列。形态与 [获取未撮合订单](/zh/pages/rest/user/get-unmatched-orders) 相同。
</ResponseField>
<ResponseField name="data.matched" type="array">
  该赛事上已撮合（未结算）投注的数组。形态与 [获取已撮合投注](/zh/pages/rest/user/get-matched-bets) 相同。
</ResponseField>

### 示例 {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## 错误 {#errors}

| 状态 | 含义 |
| ------ | ------- |
| `404`  | `gameID` 缺失或不是有效的赛事 ID。 |
