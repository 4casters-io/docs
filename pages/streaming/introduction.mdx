---
title: '4casters Streaming API'
---

The 4casters streaming API delivers real-time user and market updates over a raw WebSocket connection.

## Endpoints
- **User feed**: `wss://streaming-api.4casters.io/v2/user`
- **Price feed**: `wss://streaming-api.4casters.io/price-stream`

The price feed broadcasts all market updates by default. Clients can optionally narrow the stream to specific games, leagues, or sports — see [Subscriptions](/pages/streaming/price-feed#subscriptions).

## Auth

Both feeds authenticate with a 4casters credential in the `Authorization`
header on the WebSocket handshake: an [API key](/pages/rest/api-keys) (create
one on your account page; the right choice for a program) or a login token
from [`POST /user/login`](/pages/rest/authentication). The server derives the
user from the credential — **no username in the URL**. A refused credential
fails the handshake with a `401` or `403`; see [Authentication](/pages/authentication).

### Connect

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const ws = new WebSocket('wss://streaming-api.4casters.io/v2/user', {
  headers: { Authorization: process.env.FOURCASTERS_API_KEY },
});
```
</CodeGroup>
