---
title: '4casters 订单 API'
---

4casters 订单 API 通过原始 WebSocket 连接支持实时下单、取消和会话管理。

## 端点 {#endpoints}
- **订单 API**：`wss://orders-api.4casters.io/orders/ws`

## 认证 {#auth}

连接使用 4Casters 令牌进行认证。在 WebSocket 握手时于
`Authorization` 请求头中发送令牌。服务器从令牌推导用户
— **URL 中无需用户名**。

### 获取令牌 {#get-a-token}

没有单独的 API 密钥。使用你的 4Casters 用户名和密码，调用 4Casters REST API 的
`/user/login` 端点登录。响应中包含可在此处使用的令牌。令牌有效期与轮换见
[认证](/zh-Hans/pages/authentication)。

见 [4Casters REST API 文档中的 `POST /user/login`](/zh-Hans/pages/rest/authentication)。

### 连接 {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const token = process.env.FOURCASTERS_TOKEN;
const ws = new WebSocket('wss://orders-api.4casters.io/orders/ws', {
  headers: { Authorization: token },
});
```
</CodeGroup>

## 消息格式 {#message-format}

每个客户端请求都是二元组 `[messageType, payload]`。每个载荷都应包含你生成的 `requestID`；服务器会原样回传，以便你关联响应。

<CodeGroup>
```json 请求
[
  "messageType",
  {
    "requestID": "YOUR_REQUEST_ID",
    "...": "..."
  }
]
```
</CodeGroup>

服务器响应是带有 `requestID` 以及 `data`（成功）或 `error`（失败）的 JSON 对象：

<CodeGroup>
```json 成功
{
  "requestID": "YOUR_REQUEST_ID",
  "data": { "...": "..." }
}
```

```json 错误
{
  "requestID": "YOUR_REQUEST_ID",
  "error": "human-readable error"
}
```
</CodeGroup>
