---
title: '获取赛事'
description: '列出某联赛的活跃赛事'
openapi: 'GET /exchange/v2/getGames'
---

返回某联赛的全部活跃赛事。响应**不**包含订单簿或任何价格 — 请调用 [获取订单簿](/zh-Hans/pages/rest/markets/get-orderbook) 获取。

## 请求 {#request}

`GET /exchange/v2/getGames`

<ParamField query="league" type="string" required>
  来自 [获取联赛](/zh-Hans/pages/rest/markets/get-leagues) 的联赛代码。使用特殊值 `upcoming` 可获取跨联赛的全部即将开赛赛事。
</ParamField>
<ParamField query="sport" type="string">
  可选的运动项目过滤。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/v2/getGames?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.games" type="array">
  <Expandable title="Game">
    <ResponseField name="id"             type="string">赛事 ID。</ResponseField>
    <ResponseField name="parentGameID"   type="string">父赛事 ID（若这是子市场：附加盘、分段盘）。</ResponseField>
    <ResponseField name="cheapDataUID"   type="string">赛事的稳定跨系统标识（用于盘口关联）。</ResponseField>
    <ResponseField name="league"         type="string" />
    <ResponseField name="sport"          type="string" />
    <ResponseField name="start"          type="string">ISO 8601 开赛时间。</ResponseField>
    <ResponseField name="ended"          type="boolean" />
    <ResponseField name="live"           type="boolean" />
    <ResponseField name="featured"       type="boolean" />
    <ResponseField name="eventName"      type="string" />
    <ResponseField name="tournamentName" type="string" />
    <ResponseField name="periodName"     type="string">例如 `Full Time`、`1H`、`Set 1`。</ResponseField>
    <ResponseField name="isSpecials"     type="boolean">期货盘及其他特殊盘为 `true`。</ResponseField>
    <ResponseField name="participants"   type="array">二元 `[away, home]` 数组。每个参赛方有 `id`、`longName`、`shortName`、`homeAway`、`mainPitcher`、`rotationNumber`、`futuresSide`。</ResponseField>
  </Expandable>
</ResponseField>
