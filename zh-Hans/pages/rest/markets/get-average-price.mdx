---
title: '获取均价'
description: '某联赛中每场赛事的最优价与均价'
openapi: 'GET /exchange/getOddsForAveragePrice'
---

返回某联赛中每场赛事的最优价与均价的截断列表。对每场赛事和每个市场（moneyline / spread / total），响应包含：

- **最优价格**（最优挂单上的价格）；
- 扫掉至少 **$500** 流动性时你会支付的**均价**；
- 可按最优价格和均价成交的**最大投注额**。

每个赛事上的按市场数组（`awayMoneylines`、`homeMoneylines` 等）已被剥离；仅保留汇总的 `odds` 块。

<Note>
与大多数端点不同，此端点在**顶层**返回赛事（不在 `data` 下）。
</Note>

## 请求 {#request}

`GET /exchange/getOddsForAveragePrice`

<ParamField query="leagueRequested" type="string" required>
  联赛代码（不区分大小写）。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getOddsForAveragePrice?leagueRequested=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>
