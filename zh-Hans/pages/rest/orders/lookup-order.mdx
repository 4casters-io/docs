---
title: '查询订单'
description: '获取你某一笔订单的当前状态'
openapi: 'GET /session/lookupOrder'
---

获取调用方某一笔订单的当前状态。返回带 `matchedRisk` / `unmatchedRisk` 核算以及底层赛事反规范化快照的订单。

## 请求 {#request}

`GET /session/lookupOrder`

<ParamField query="orderID" type="string" required>
  4casters 订单 ID。可从 `/session/v3/place` 的 `data.unmatched.orderID` 或 `/user/getUnmatched` 的 `id` 获取。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/session/lookupOrder?orderID=ORDER_ID" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.order" type="object">
  <Expandable title="order">
    <ResponseField name="id" type="string" />
    <ResponseField name="cancelled" type="boolean" />
    <ResponseField name="isTheBestOffer" type="boolean">
      当对面没有比该订单更优赔率的竞争挂单时为 `true`。
    </ResponseField>
    <ResponseField name="odds" type="integer">该订单的美式赔率（相对内部存储做了符号翻转）。</ResponseField>
    <ResponseField name="type" type="string">`moneyline`、`spread`、`total` 或 `moneyline1x2`。</ResponseField>
    <ResponseField name="OU" type="string">`total` 市场上该订单方向的对面。非大小分盘为 `null`。</ResponseField>
    <ResponseField name="participant" type="string">你下注的参赛方 ID。`total` 为 `null`。</ResponseField>
    <ResponseField name="participantLongName" type="string" />
    <ResponseField name="spread" type="number" />
    <ResponseField name="total" type="number" />
    <ResponseField name="matchedRisk" type="string">已被撮合的风险额（字符串格式，两位小数）。</ResponseField>
    <ResponseField name="unmatchedRisk" type="string">仍挂在订单簿上的剩余风险额。</ResponseField>

  </Expandable>
</ResponseField>

## 错误 {#errors}

| 状态 | 含义 |
| ------ | ------- |
| `403`  | 不是你的订单。 |
| `404`  | 无效的订单 ID。 |
