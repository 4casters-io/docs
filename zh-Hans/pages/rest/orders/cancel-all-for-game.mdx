---

---

取消单场赛事上的每一笔未成交订单。可选择限定到单一市场 `type`，以保留其他市场的订单。

## 请求 {#request}

`POST /session/cancelAllOrdersForGame`

<ParamField body="gameID" type="string" required>
  应取消订单的赛事。
</ParamField>
<ParamField body="type" type="string">
  可选。仅取消该市场类型的订单 — 取值为 `moneyline`、`spread`、`total` 之一。省略时取消所有市场类型。
</ParamField>

<CodeGroup>
```bash curl（单个市场）
curl -X POST https://api.4casters.io/session/cancelAllOrdersForGame \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "gameID": "688c0516fbc14da0c202d426",
    "type": "spread"
  }'
```

```bash curl（全部市场）
curl -X POST https://api.4casters.io/session/cancelAllOrdersForGame \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "gameID": "688c0516fbc14da0c202d426" }'
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data" type="array">
  按单取消结果。形态与 [取消一笔订单](/zh-Hans/pages/rest/orders/cancel-order#response) 相同。
</ResponseField>

## 错误 {#errors}

| 状态 | 含义 |
| ------ | ------- |
| `400`  | `gameID` 缺失 / 无效，或 `type` 不是允许的取值之一。 |
