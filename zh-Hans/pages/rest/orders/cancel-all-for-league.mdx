---
title: '取消某联赛的全部订单'
description: '异步取消某联赛中的每一笔未成交订单'
openapi: 'POST /session/cancelAllForLeague'
---

安排取消某联赛中的每一笔未成交订单。此端点**异步处理** — 立即以 `{ ordersReceived: true }` 确认，取消在后台进行。

若需要知道哪些订单被取消，请随后调用 [获取未撮合订单](/zh-Hans/pages/rest/user/get-unmatched-orders)，或订阅 [WebSocket 推送 API](/zh-Hans/pages/streaming/user-feed) 上的用户推送。

## 请求 {#request}

`POST /session/cancelAllForLeague`

<ParamField body="league" type="string" required>
  联赛代码。列表可从 `GET /exchange/getLeagues` 获取。不区分大小写。
</ParamField>

<CodeGroup>
```bash curl
curl -X POST https://api.4casters.io/session/cancelAllForLeague \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "league": "NBA" }'
```
</CodeGroup>

## 响应 {#response}

<ResponseField name="data.ordersReceived" type="boolean">
  成功时始终为 `true`。取消操作异步处理。
</ResponseField>

### 示例 {#example}

<CodeGroup>
```json JSON
{ "data": { "ordersReceived": true } }
```
</CodeGroup>

## 错误 {#errors}

| 状态 | 含义 |
| ------ | ------- |
| `400`  | `league` 缺失、不是字符串，或未知。 |
