---
title: 'API de órdenes de 4casters'
---

La API de órdenes de 4casters permite colocar y cancelar órdenes en tiempo real y gestionar la sesión por una conexión WebSocket cruda.

## Endpoints {#endpoints}
- **API de órdenes**: `wss://orders-api.4casters.io/orders/ws`

## Autenticación {#auth}

La conexión se autentica con una credencial de 4casters en el encabezado
`Authorization` del handshake WebSocket: una [clave de API](/es/pages/rest/api-keys)
(créala en la página de tu cuenta; la opción correcta para un programa) o un token de
inicio de sesión de [`POST /user/login`](/es/pages/rest/authentication). El servidor deriva el
usuario a partir de la credencial: **sin nombre de usuario en la URL**. Una credencial
rechazada hace fallar el handshake con un `401` o `403`; consulta [Autenticación](/es/pages/authentication).

### Conectar {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const ws = new WebSocket('wss://orders-api.4casters.io/orders/ws', {
  headers: { Authorization: process.env.FOURCASTERS_API_KEY },
});
```
</CodeGroup>

## Formato de mensajes {#message-format}

Cada solicitud del cliente es una 2-tupla `[messageType, payload]`. Cada payload debe incluir un `requestID` que tú generas; el servidor lo devuelve para que puedas correlacionar las respuestas.

<CodeGroup>
```json Request
[
  "messageType",
  {
    "requestID": "YOUR_REQUEST_ID",
    "...": "..."
  }
]
```
</CodeGroup>

Las respuestas del servidor son objetos JSON con `requestID` más `data` (éxito) o `error` (fallo):

<CodeGroup>
```json Success
{
  "requestID": "YOUR_REQUEST_ID",
  "data": { "...": "..." }
}
```

```json Error
{
  "requestID": "YOUR_REQUEST_ID",
  "error": "human-readable error"
}
```
</CodeGroup>

## Límites de tasa {#rate-limits}

Colocar órdenes tiene un límite por cuenta, compartido con REST. Se aplica desde el 2026-11-02. Al superar el límite recibes `error_type` `rate_limited` con `retryAfterMs`, y la conexión sigue abierta. Las cancelaciones y los heartbeats nunca tienen límite.

Consulta [Límites de tasa](/es/pages/rate-limiting).
