---
title: 'Obtener juegos'
description: 'Lista los juegos activos de una liga'
openapi: 'GET /exchange/v2/getGames'
---

Devuelve todos los juegos activos de una liga. La respuesta **no** incluye el libro de órdenes ni ningún precio: llama a [Obtener libro de órdenes](/es/pages/rest/markets/get-orderbook) para eso.

## Solicitud {#request}

`GET /exchange/v2/getGames`

<ParamField query="league" type="string" required>
  Código de liga de [Obtener ligas](/es/pages/rest/markets/get-leagues). Usa el valor especial `upcoming` para obtener todos los juegos próximos de todas las ligas.
</ParamField>
<ParamField query="sport" type="string">
  Filtro opcional de deporte.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/v2/getGames?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Respuesta {#response}

<ResponseField name="data.games" type="array">
  <Expandable title="Game">
    <ResponseField name="id"             type="string">Id del juego.</ResponseField>
    <ResponseField name="parentGameID"   type="string">Id del juego padre, si este es un mercado hijo (props, periodos alternativos).</ResponseField>
    <ResponseField name="cheapDataUID"   type="string">Identificador estable entre sistemas del juego (se usa para correlación de líneas).</ResponseField>
    <ResponseField name="league"         type="string" />
    <ResponseField name="sport"          type="string" />
    <ResponseField name="start"          type="string">Hora de inicio en ISO 8601.</ResponseField>
    <ResponseField name="ended"          type="boolean" />
    <ResponseField name="live"           type="boolean" />
    <ResponseField name="featured"       type="boolean" />
    <ResponseField name="eventName"      type="string" />
    <ResponseField name="tournamentName" type="string" />
    <ResponseField name="periodName"     type="string">p. ej. `Full Time`, `1H`, `Set 1`.</ResponseField>
    <ResponseField name="isSpecials"     type="boolean">`true` en mercados de futuros y otros especiales.</ResponseField>
    <ResponseField name="participants"   type="array">Array de dos elementos `[away, home]`. Cada participante tiene `id`, `longName`, `shortName`, `homeAway`, `mainPitcher`, `rotationNumber`, `futuresSide`.</ResponseField>
  </Expandable>
</ResponseField>
