---
title: 'Obtener libro de órdenes'
description: 'Lee el libro de órdenes de una liga o juego (v2, recomendado)'
openapi: 'GET /exchange/v2/getOrderbook'
---

Devuelve el libro de órdenes de una liga o de un solo juego en forma **plana**: cada mercado es un array de órdenes en lugar de un objeto indexado por spread / total.

Este es el endpoint de libro de órdenes recomendado. Combínalo con el feed de precios de [Streaming WebSocket](/es/pages/streaming/price-feed) para actualizaciones en tiempo real.

## Solicitud

`GET /exchange/v2/getOrderbook`

<ParamField query="league" type="string">
  Código de liga, p. ej. `NBA` (no distingue mayúsculas). Obligatorio cuando no se proporciona `gameID`.
</ParamField>
<ParamField query="sport" type="string">
  Nombre del deporte, p. ej. `basketball` (no distingue mayúsculas). Filtro opcional cuando está definido `league`.
</ParamField>
<ParamField query="gameID" type="string">
  Id de un solo juego. Cuando se proporciona, se ignoran `league` y `sport`.
</ParamField>

<CodeGroup>
```bash curl (one league)
curl "https://api.4casters.io/exchange/v2/getOrderbook?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (one game)
curl "https://api.4casters.io/exchange/v2/getOrderbook?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Respuesta {#response}

<ResponseField name="data.games" type="array">
  Cada `game` tiene la forma estándar de [Game](/es/pages/rest/markets/get-games#response) con los siguientes arrays adicionales por mercado:

  <Expandable title="Campos del libro de órdenes por juego">
    <ResponseField name="awayMoneylines"    type="array">Órdenes moneyline en espera a favor del equipo visitante. Ordenadas con el mejor precio primero.</ResponseField>
    <ResponseField name="homeMoneylines"    type="array">Órdenes moneyline en espera a favor del equipo local.</ResponseField>
    <ResponseField name="awaySpreads"       type="array">Órdenes spread en espera del lado visitante, aplanadas entre números de spread.</ResponseField>
    <ResponseField name="homeSpreads"       type="array">Órdenes spread en espera del lado local.</ResponseField>
    <ResponseField name="over"              type="array">Órdenes `over` en espera, aplanadas entre totals.</ResponseField>
    <ResponseField name="under"             type="array">Órdenes `under` en espera.</ResponseField>
    <ResponseField name="awayMoneylines1x2" type="array">**Solo fútbol.** Órdenes de moneyline a tres vías a favor del equipo visitante.</ResponseField>
    <ResponseField name="homeMoneylines1x2" type="array">**Solo fútbol.** Órdenes de moneyline a tres vías a favor del equipo local.</ResponseField>
    <ResponseField name="draw1x2"           type="array">**Solo fútbol.** Órdenes de moneyline a tres vías sobre el empate.</ResponseField>
    <ResponseField name="openInterest"      type="number">Suma de `bet` de cada orden en espera del juego.</ResponseField>
    <ResponseField name="matchedVolume"     type="number">Volumen total cruzado en este juego.</ResponseField>
  </Expandable>
</ResponseField>
