---
title: 'Obtener exposición del juego'
description: 'Pérdida en el peor caso de un solo juego'
openapi: 'GET /user/getGameLiability'
---

Calcula la **exposición financiera en el peor caso** de la cuenta autenticada para un solo juego, teniendo en cuenta cada apuesta en cada mercado del juego.

El valor siempre es `<= 0`: incluso un libro totalmente cubierto puede incurrir en pérdida por cancelaciones por lluvia, suspensiones o descalificaciones.

## Solicitud {#request}

`GET /user/getGameLiability`

<ParamField query="gameID" type="string" required>El id del juego para el que se calcula la exposición.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getGameLiability?gameID=657f8ea1ea0ce6f62c1fe37d" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Respuesta {#response}

<ResponseField name="data.liability" type="number">
  La pérdida en el peor caso, en la moneda de la cuenta. Siempre `<= 0`. Devuelve `0` cuando la cuenta autenticada no tiene apuestas en el juego.
</ResponseField>

### Ejemplo {#example}

<CodeGroup>
```json JSON
{
  "data": { "liability": -125.50 }
}
```
</CodeGroup>
