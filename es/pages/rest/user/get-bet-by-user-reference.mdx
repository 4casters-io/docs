---
title: 'Obtener apuesta por referencia de usuario'
description: 'Consulta cada apuesta ligada a un identificador definido por el cliente'
openapi: 'GET /user/getBetByUserReference'
---

Consulta cada apuesta ligada a un `userReference`. `userReference` es una cadena opcional definida por el cliente que puedes adjuntar a una orden al colocarla para rastrearla de tu lado: este endpoint es la contraparte de lectura.

La respuesta separa los resultados en tres grupos:

- `unmatched` — ofertas abiertas de esta referencia que siguen en el libro.
- `matched`   — apuestas cruzadas (no liquidadas) de esta referencia.
- `graded`    — apuestas liquidadas de esta referencia, incluyendo `risk`, `win`, `fee` y `result`.

## Solicitud {#request}

`GET /user/getBetByUserReference`

<ParamField query="userReference" type="string" required>
  Referencia definida por el cliente, pasada en el momento de colocación.
</ParamField>
<ParamField query="gameID" type="string" required>
  Limita la consulta a un solo juego.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getBetByUserReference?userReference=my-order-1&gameID=67d1c942215edc7ee0c806ef" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Respuesta {#response}

<ResponseField name="data.unmatched" type="array">
  Órdenes abiertas — misma forma que [Obtener órdenes no cruzadas](/es/pages/rest/user/get-unmatched-orders#response).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Apuestas cruzadas (no liquidadas) — misma forma que [Obtener apuestas cruzadas](/es/pages/rest/user/get-matched-bets#response).
</ResponseField>
<ResponseField name="data.graded" type="array">
  Apuestas liquidadas — misma forma que [Obtener apuestas liquidadas](/es/pages/rest/user/get-graded-wagers#response).
</ResponseField>

## Errores {#errors}

| Estado | Significado |
| ------ | ------- |
| `408`  | Falta `userReference` o `gameID`. |
