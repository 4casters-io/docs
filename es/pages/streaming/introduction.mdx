---
title: 'API de streaming de 4casters'
---

La API de streaming de 4casters entrega actualizaciones de usuario y de mercado en tiempo real por una conexión WebSocket cruda.

## Endpoints {#endpoints}
- **Feed de usuario**: `wss://streaming-api.4casters.io/v2/user`
- **Feed de precios**: `wss://streaming-api.4casters.io/price-stream`

El feed de precios difunde todas las actualizaciones de mercado por defecto. Los clientes pueden acotar el stream a juegos, ligas o deportes concretos: consulta [Suscripciones](/es/pages/streaming/price-feed#subscriptions).

## Autenticación {#auth}

Ambos feeds se autentican con una credencial de 4casters en el encabezado
`Authorization` del handshake WebSocket: una [clave de API](/es/pages/rest/api-keys)
(créala en la página de tu cuenta; la opción correcta para un programa) o un token de
inicio de sesión de [`POST /user/login`](/es/pages/rest/authentication). El servidor deriva el
usuario a partir de la credencial: **sin nombre de usuario en la URL**. Una credencial
rechazada hace fallar el handshake con un `401` o `403`; consulta [Autenticación](/es/pages/authentication).

### Conectar {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const ws = new WebSocket('wss://streaming-api.4casters.io/v2/user', {
  headers: { Authorization: process.env.FOURCASTERS_API_KEY },
});
```
</CodeGroup>
