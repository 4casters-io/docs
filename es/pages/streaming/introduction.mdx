---
title: 'API de streaming de 4casters'
---

La API de streaming de 4casters entrega actualizaciones de usuario, de mercado y de juego en tiempo real por una conexión WebSocket cruda.

## Endpoints {#endpoints}
- **Feed de usuario**: `wss://streaming-api.4casters.io/v2/user`
- **Feed de precios**: `wss://streaming-api.4casters.io/price-stream`
- **Feed de puntuaciones**: `wss://streaming-api.4casters.io/v1/score`

El feed de precios difunde todas las actualizaciones de mercado por defecto. Los clientes pueden acotar el stream a juegos, ligas o deportes concretos: consulta [Suscripciones](/es/pages/streaming/price-feed#subscriptions).

El feed de puntuaciones difunde el estado en vivo de los juegos: marcador, periodo, reloj y el detalle que importa en cada deporte. Usa los mismos comandos de suscripción que el feed de precios y, además, envía el estado actual de todos los juegos en vivo suscritos al conectar: consulta [Instantáneas al conectar](/es/pages/streaming/score-feed#snapshot-on-connect).

## Autenticación {#auth}

Ambos feeds se autentican con un token de 4Casters. Envía el token en el
encabezado `Authorization` del handshake WebSocket. El servidor deriva el usuario
a partir del token: **sin nombre de usuario en la URL**.

### Obtener un token {#get-a-token}

No hay una clave de API aparte. Inicia sesión con tu nombre de usuario y contraseña
de 4Casters llamando al endpoint `/user/login` de la API REST de 4Casters. La respuesta
incluye un token que puedes usar aquí. Consulta [Autenticación](/es/pages/authentication)
para la vida útil y la rotación del token.

Consulta [`POST /user/login` en la documentación de la API REST de 4Casters](/es/pages/rest/authentication).

### Conectar {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const token = process.env.FOURCASTERS_TOKEN;
const ws = new WebSocket('wss://streaming-api.4casters.io/v2/user', {
  headers: { Authorization: token },
});
```
</CodeGroup>
