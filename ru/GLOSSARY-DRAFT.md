# Глоссарий (ru) — ЧЕРНОВИК

> **Статус: черновик для носителя языка (Gate 2).** Термины выбраны до перевода и применены единообразно по всему дереву `ru/`. Менять термин — значит менять эту таблицу **и каждое вхождение на страницах в одном коммите** (см. TRANSLATIONS.md).

Обращение к читателю: формальное **вы** (со строчной буквы), как принято в русской технической документации.

Числа, суммы, коэффициенты и проценты остаются в формате `en-US` (решение PM, 2026-09-01): `3,000` остаётся `3,000`, `1%` остаётся `1%`.

## Остаются на английском

`WebSocket`, `REST`, `maker`, `taker`, `heartbeat`, `token` — везде без перевода.

`moneyline`, `spread`, `total` — без перевода, с кратким пояснением при первом употреблении на странице: `moneyline` (ставка на победителя), `spread` (фора), `total` (тотал).

Имена полей API (`matched`, `unmatched`, `bet`, `risk`, `win` и т. д.) в обратных кавычках — всегда байт-в-байт как в английском (правило 2).

## Пары, которые нельзя смешивать

- **риск** (`risk` — сумма ставки) ≠ **ответственность** (liability — худший возможный убыток по игре). Это разные величины; фронтенд обязан различать их так же.
- **ставка** (bet) ≠ **пари** (wager) — API различает bet и graded wager.
- **сведённый** (matched — сделка произошла) ≠ **исполнение** (fill — акт сведения части объёма).
