Фид цен передаёт обновления рынков / книги ордеров в виде JSON-сообщений по «сырому» WebSocket-соединению.

<CodeGroup>
```javascript JavaScript
// price_feed_quickstart.js 
const WebSocket = require('ws'); 
const token = process.env.FOURCASTERS_TOKEN; 
 
function connectPriceFeed() { 
  const ws = new 
  WebSocket('wss://streaming-api.4casters.io/price-stream', { 
    headers: { Authorization: token }, 
  }); 
 
  let pingTimer; let lastPong = Date.now(); 
 
  ws.on('open', () => { 
    console.log('price stream connected'); 

    // Optional: narrow the feed to specific games / leagues / sports.
    // Omit this block to receive all market updates (default). 
    ws.send(JSON.stringify({ 
      type: 'subscribe', 
      gameIDs: [], 
      leagueIDs: ['NBA'], 
      sportIDs: [], 
      replace: true, 
    })); 

    pingTimer = setInterval(() => { 
      if (ws.readyState === WebSocket.OPEN) ws.ping(); 
      if (Date.now() - lastPong > 30000) { 
        console.warn('price stream: missed pong >30s, closing'); 
        ws.terminate(); 
      } 
    }, 10000); 
  }); 
 
  ws.on('pong', () => { lastPong = Date.now(); }); 
 
  ws.on('message', (buf) => { 
    try { 
      const msg = JSON.parse(buf.toString()); 
      console.log('price update:', JSON.stringify(msg, null, 2)); 
    } catch { console.log('price update (raw):', buf.toString()); } 
  }); 
 
  ws.on('error', (e) => console.error('price stream error:', e.message)); 
 
  ws.on('close', (code, reason) => { 
    console.log(`price stream closed: ${code} ${reason}`); 
    clearInterval(pingTimer); 
    setTimeout(connectPriceFeed, 1000); 
  }); 
} 
connectPriceFeed();
```
</CodeGroup>

## Ping/Pong {#ping-pong}
Оба фида поддерживают стандартный WebSocket `ping/pong`. Вы можете проактивно вызывать `ping()` с интервалом и отслеживать `pong`, чтобы проверять живость соединения.

## Подписки {#subscriptions}

По умолчанию подключённый клиент получает каждое обновление рынков по всем видам спорта и лигам. Чтобы сузить этот поток, отправьте одну из следующих команд как текстовый JSON-фрейм после того, как сокет перешёл в состояние `open`. Команды действуют в течение всего времени жизни соединения.

Клиент, который никогда не отправляет команду подписки, остаётся в режиме полной трансляции, поэтому существующие интеграции продолжают работать без изменений.

### Подписка по gameID, лиге или виду спорта {#subscribe-by-gameid-league-or-sport}

Устанавливает фильтр. `gameIDs` — 24-символьные шестнадцатеричные строки Mongo ObjectID; `leagueIDs` — короткие коды вроде `NBA` / `MLB` / `EPL`; `sportIDs` — токены в нижнем регистре вроде `basketball` / `baseball` / `soccer`.

<CodeGroup>
```json Замена (рекомендуется)
{
  "type": "subscribe",
  "gameIDs": ["62619dce25e2fb049a71cc2e"],
  "leagueIDs": ["NBA"],
  "sportIDs": [],
  "replace": true
}
```
```json Добавление
{
  "type": "subscribe",
  "gameIDs": [],
  "leagueIDs": ["MLB"],
  "sportIDs": [],
  "replace": false
}
```
</CodeGroup>

- `replace: true` очищает все существующие подписки на этом соединении и устанавливает новые списки. Переводит соединение в режим фильтрации.
- `replace: false` добавляет новые ключи к тому, на что соединение уже подписано.

Вы получите обновление, если его `gameID`, `parentGameID`, `league` или `sport` совпадает с любой из ваших подписок.

### Отписка {#unsubscribe}

Удаляет конкретные ключи. Соединение остаётся в своём текущем режиме (фильтрация или подписка на всё).

<CodeGroup>
```json JSON
{
  "type": "unsubscribe",
  "gameIDs": [],
  "leagueIDs": ["MLB"],
  "sportIDs": []
}
```
</CodeGroup>

### Подписка на всё {#subscribe-to-everything}

Явная подписка на всё сразу. Полезна, если ранее вы сузили поток через `subscribe` и хотите снова расширить его без переподключения. Очищает все поимённые подписки на соединении.

<CodeGroup>
```json JSON
{ "type": "subscribeAll" }
```
</CodeGroup>

### Семантика маршрутизации {#routing-semantics}

- Подписка на `gameID` также получает обновления дочерних игр, чей `parentGameID` совпадает (например, деривативы F5-MLB доходят до подписчиков родительской игры).
- ID лиг нечувствительны к регистру — `mlb` и `MLB` эквивалентны.
- ID видов спорта нечувствительны к регистру — `baseball` и `Baseball` эквивалентны.
- Пустые строки внутри массивов игнорируются.
- `subscribe` с `replace: false` **и** полностью пустыми массивами — это no-op (клиент с багом не может случайно отправить себя в «чёрную дыру», послав пустую добавляющую подписку).
- `subscribe` с `replace: true` **и** полностью пустыми массивами — легитимный способ «очистить все мои подписки»: соединение входит в режим фильтрации с нулём подписок и не получает ничего, пока вы не подпишетесь снова или не отправите `subscribeAll`.

## Сообщения {#messages}

Каждое сообщение на `/price-stream` приходит как 2-кортеж `[type, payload]`. Транслируются три типа сообщений.

### `orderUpdate` {#orderupdate}
