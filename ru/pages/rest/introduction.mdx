REST API 4casters позволяет программно выполнять вход, запрашивать игры и книгу ордеров, размещать / изменять / отменять ордера и читать историю своих ставок. Это тот же API, на котором работает веб-приложение 4casters.

## Базовый URL {#base-url}

Все эндпоинты этого раздела имеют корень:

```
https://api.4casters.io
```

## Соглашения {#conventions}

- **Транспорт**: только HTTPS.
- **Кодирование**: JSON. Отправляйте `Content-Type: application/json` в каждом запросе с телом.
- **Конверт ответа**: за парой явно отмеченных исключений (`/affiliate/getAffiliateCommission`, `/exchange/getOddsForAveragePrice`) каждый успешный ответ обёрнут: `{ "data": <payload> }`.
- **Идентификаторы**: id игр, участников и ордеров — строки MongoDB `ObjectID` (24 шестнадцатеричных символа).
- **Коэффициенты**: все коэффициенты в американском формате (отрицательные для фаворитов, положительные для андердогов), если не указано иное.
- **Время**: все временные метки в ISO 8601 с `Z` (UTC).

## Аутентификация {#authentication}

Почти каждый эндпоинт требует аутентификации. Выполните вход один раз через [POST `/user/login`](/ru/pages/rest/authentication), затем отправляйте полученный token в каждом запросе — подробности в разделе [Аутентификация](/ru/pages/rest/authentication).

## Поштучные ошибки и HTTP-ошибки {#per-order-errors-vs-http-errors}

Эндпоинты размещения и изменения принимают пакеты и возвращают результаты по каждому ордеру. Успешный ответ HTTP `200` всё равно может содержать отказы по отдельным ордерам внутри `data.createdSessions[i]`. Формат поштучной ошибки описан на странице каждого эндпоинта.

Ошибки уровня HTTP (`4xx`, `5xx`) возвращаются как `{ "error": "<message>" }`.

## Ограничение частоты запросов {#rate-limiting}

Действуют три уровня ограничения частоты:

- **Глобальный, на IP** — каждый запрос к API расходует бюджет **3,000 запросов на скользящее 60-секундное окно** для каждого IP (устойчиво ~50 запросов/секунду). При превышении возвращается `429` с заголовком `Retry-After` (в секундах) и телом `{ "error": "Too many requests. Please try again later." }`.
- **Маршруты аутентификации** (`/user/login`, сброс пароля, регистрация) имеют дополнительное ограничение на IP и на аккаунт.
- **Маршруты размещения / изменения / отмены** дополнительно ограничены по аккаунту.

Эндпоинты чтения не имеют лимита на аккаунт — действует только глобальный потолок на IP.

## Тайм-ауты {#timeouts}

Запросы, обрабатывающиеся на сервере дольше **15 секунд**, прерываются и возвращают `503` с телом `{ "error": { "message": "Network Error", "code": 503 } }`.

## Обновления в реальном времени {#real-time-updates}

REST API работает в паре со [стриминговым WebSocket API](/ru/pages/streaming/introduction), который даёт тики книги ордеров и события исполнения / расчёта по аккаунту в реальном времени. Token, возвращаемый `/user/login`, действует для обоих.
