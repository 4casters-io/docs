Поиск одной ставки (сведённой, рассчитанной или открытого предложения), принадлежащей вызывающему. Передайте **либо** `id`, **либо** `txID`, но не оба.

## Запрос {#request}

`GET /user/getBetByID`

<ParamField query="id" type="string">
  `id` ставки из спискового эндпоинта, такого как `/user/getMatchedBets`.
</ParamField>
<ParamField query="txID" type="string">
  Id транзакции, например `wagerRequestID` или `txID`, возвращённый `/session/v3/place`.
</ParamField>

Нужно передать ровно один из `id` или `txID`.

<CodeGroup>
```bash curl (по txID)
curl "https://api.4casters.io/user/getBetByID?txID=64824b329556daa319747e31" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (по id)
curl "https://api.4casters.io/user/getBetByID?id=6494ca85c9346058f35b2b1e" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

Формат `bet` зависит от текущего состояния ставки:

- **Рассчитанная** ставка возвращается в формате [GradedWager](/ru/pages/rest/user/get-graded-wagers#response), включая `risk`, `win`, `fee` и `result`.
- **Сведённая** ставка возвращается в формате [MatchedBet](/ru/pages/rest/user/get-matched-bets#response).
- **Открытое предложение** возвращается в формате [UnmatchedOrder](/ru/pages/rest/user/get-unmatched-orders#response).

Обратите внимание: в отличие от большинства эндпоинтов, этот возвращает ставку на **верхнем уровне** (не под `data`).

## Ошибки {#errors}

| Статус | Значение |
| ------ | ------- |
| `400`  | Отсутствуют и `id`, и `txID`, либо по переданному идентификатору ставка не найдена. |
