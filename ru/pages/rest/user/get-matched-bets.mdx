---
title: 'Получить сведённые ставки'
description: 'Список ставок, которые сведены, но ещё не рассчитаны'
openapi: 'GET /user/getMatchedBets'
---

Возвращает все ставки вызывающего, которые **сведены, но ещё не рассчитаны** — то есть открытые позиции по играм, расчёт которых ещё не произведён.

## Запрос {#request}

`GET /user/getMatchedBets`

Не принимает параметров.

<CodeGroup>
```bash curl
curl https://api.4casters.io/user/getMatchedBets \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

<ResponseField name="data.matchedBets" type="array">
  Массив сведённых ставок, отсортированный по возрастанию времени начала игры.
  <Expandable title="MatchedBet">
    <ResponseField name="id" type="string">Id ставки.</ResponseField>
    <ResponseField name="txID" type="string">Id транзакции исполнения.</ResponseField>
    <ResponseField name="type" type="string">`moneyline` (ставка на победителя), `spread` (фора), `total` (тотал) или `moneyline1x2`.</ResponseField>
    <ResponseField name="bet" type="number">Исходный размер ставки.</ResponseField>
    <ResponseField name="odds" type="integer">Американские коэффициенты на момент исполнения.</ResponseField>
    <ResponseField name="spread" type="number">Присутствует для `spread`.</ResponseField>
    <ResponseField name="total" type="number">Присутствует для `total`.</ResponseField>
    <ResponseField name="OU" type="string">`over` или `under`. Присутствует для `total`.</ResponseField>
    <ResponseField name="participantID" type="string">Присутствует для `moneyline` и `spread`.</ResponseField>
    <ResponseField name="market" type="string">Присутствует для `moneyline1x2`.</ResponseField>
    <ResponseField name="side" type="string">Для `moneyline1x2` — `yes` или `no`.</ResponseField>
    <ResponseField name="userReference" type="string">Необязательный определяемый клиентом идентификатор, переданный при размещении.</ResponseField>
    <ResponseField name="createdAt" type="string">Временная метка ISO 8601.</ResponseField>
    <ResponseField name="matchedTime" type="string">Временная метка ISO 8601, когда произошло исполнение.</ResponseField>
    <ResponseField name="origin" type="string">`offer` (вы разместили, taker взял ваше предложение) или `wager` (вы взяли ожидающую ликвидность).</ResponseField>
    <ResponseField name="risk" type="string">Риск на сведённую часть (строка, 2 знака после запятой). Включает комиссию, которую вы заплатили бы при проигрыше.</ResponseField>
    <ResponseField name="win" type="string">Сумма выигрыша за вычетом комиссии, которую вы заплатили бы при выигрыше. Отдельного поля `fee` у сведённых ставок нет — комиссия взимается при расчёте и появляется только у рассчитанных пари; до этого она отражена в `risk`/`win`.</ResponseField>
    <ResponseField name="graded" type="boolean">Здесь всегда `false`.</ResponseField>
    <ResponseField name="closed" type="boolean">Была ли ставка закрыта действием администратора.</ResponseField>
    <ResponseField name="adminRefund" type="boolean">Была ли ставка возвращена администратором.</ResponseField>
    <Snippet file="ru/types/game-summary.mdx" />
  </Expandable>
</ResponseField>
