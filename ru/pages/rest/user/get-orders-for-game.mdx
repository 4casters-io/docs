---
title: 'Получить ордера по игре'
description: 'Список ваших открытых ордеров и сведённых ставок по одной игре'
openapi: 'GET /user/getOrdersForGame'
---

Для заданного id игры 4casters возвращает открытые ордера и сведённые (нерассчитанные) ставки вызывающего по этой игре. Рассчитанные ставки этот эндпоинт не возвращает — для них используйте [Получить рассчитанные пари](/ru/pages/rest/user/get-graded-wagers).

## Запрос {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>Id игры 4casters.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

<ResponseField name="data.unmatched" type="array">
  Массив открытых ордеров по игре, отсортированный по возрастанию времени начала игры. Тот же формат, что и в [Получить несведённые ордера](/ru/pages/rest/user/get-unmatched-orders).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Массив сведённых (нерассчитанных) ставок по игре. Тот же формат, что и в [Получить сведённые ставки](/ru/pages/rest/user/get-matched-bets).
</ResponseField>

### Пример {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## Ошибки {#errors}

| Статус | Значение |
| ------ | ------- |
| `404`  | `gameID` отсутствует или не является валидным id игры. |
