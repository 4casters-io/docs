Возвращает книгу ордеров для лиги или одной игры в **плоском** виде: каждый рынок — это массив ордеров, а не объект с ключами по форе / тоталу.

Это рекомендуемый эндпоинт книги ордеров. Используйте его в паре с фидом цен [стримингового WebSocket](/ru/pages/streaming/price-feed) для обновлений в реальном времени.

## Запрос {#request}

`GET /exchange/v2/getOrderbook`

<ParamField query="league" type="string">
  Код лиги, например `NBA` (нечувствителен к регистру). Обязателен, если `gameID` не передан.
</ParamField>
<ParamField query="sport" type="string">
  Название вида спорта, например `basketball` (нечувствительно к регистру). Необязательный фильтр при заданной `league`.
</ParamField>
<ParamField query="gameID" type="string">
  Id одной игры. Если передан, `league` и `sport` игнорируются.
</ParamField>

<CodeGroup>
```bash curl (одна лига)
curl "https://api.4casters.io/exchange/v2/getOrderbook?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (одна игра)
curl "https://api.4casters.io/exchange/v2/getOrderbook?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

<ResponseField name="data.games" type="array">
  Каждая `game` — стандартный формат [Game](/ru/pages/rest/markets/get-games#response) со следующими дополнительными массивами по рынкам:

  <Expandable title="Поля книги ордеров по игре">
    <ResponseField name="awayMoneylines"    type="array">Ожидающие ордера moneyline (манилайн — ставка на победителя) на гостевую команду. Отсортированы от лучшей цены.</ResponseField>
    <ResponseField name="homeMoneylines"    type="array">Ожидающие ордера moneyline на домашнюю команду.</ResponseField>
    <ResponseField name="awaySpreads"       type="array">Ожидающие ордера spread (фора) на гостевую сторону, сведённые в плоский список по всем числам форы.</ResponseField>
    <ResponseField name="homeSpreads"       type="array">Ожидающие ордера spread на домашнюю сторону.</ResponseField>
    <ResponseField name="over"              type="array">Ожидающие ордера `over` (тотал больше), сведённые в плоский список по всем тоталам.</ResponseField>
    <ResponseField name="under"             type="array">Ожидающие ордера `under`.</ResponseField>
    <ResponseField name="awayMoneylines1x2" type="array">**Только футбол.** Ордера трёхисходного манилайна на гостевую команду.</ResponseField>
    <ResponseField name="homeMoneylines1x2" type="array">**Только футбол.** Ордера трёхисходного манилайна на домашнюю команду.</ResponseField>
    <ResponseField name="draw1x2"           type="array">**Только футбол.** Ордера трёхисходного манилайна на ничью.</ResponseField>
    <ResponseField name="openInterest"      type="number">Сумма `bet` по всем ожидающим ордерам на игру.</ResponseField>
    <ResponseField name="matchedVolume"     type="number">Общий сведённый объём по этой игре.</ResponseField>
  </Expandable>
</ResponseField>
