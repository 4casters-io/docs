---
title: 'Получить игры'
description: 'Список активных игр лиги'
openapi: 'GET /exchange/v2/getGames'
---

Возвращает все активные игры лиги. Ответ **не** включает книгу ордеров или какие-либо цены — для этого вызовите [Получить книгу ордеров](/ru/pages/rest/markets/get-orderbook).

## Запрос {#request}

`GET /exchange/v2/getGames`

<ParamField query="league" type="string" required>
  Код лиги из [Получить лиги](/ru/pages/rest/markets/get-leagues). Используйте специальное значение `upcoming`, чтобы получить все предстоящие игры по всем лигам.
</ParamField>
<ParamField query="sport" type="string">
  Необязательный фильтр по виду спорта.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/v2/getGames?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

<ResponseField name="data.games" type="array">
  <Expandable title="Game">
    <ResponseField name="id"             type="string">Id игры.</ResponseField>
    <ResponseField name="parentGameID"   type="string">Id родительской игры, если это дочерний рынок (пропсы, альтернативные периоды).</ResponseField>
    <ResponseField name="cheapDataUID"   type="string">Стабильный межсистемный идентификатор игры (используется для корреляции линий).</ResponseField>
    <ResponseField name="league"         type="string" />
    <ResponseField name="sport"          type="string" />
    <ResponseField name="start"          type="string">Время начала в ISO 8601.</ResponseField>
    <ResponseField name="ended"          type="boolean" />
    <ResponseField name="live"           type="boolean" />
    <ResponseField name="featured"       type="boolean" />
    <ResponseField name="eventName"      type="string" />
    <ResponseField name="tournamentName" type="string" />
    <ResponseField name="periodName"     type="string">Например, `Full Time`, `1H`, `Set 1`.</ResponseField>
    <ResponseField name="isSpecials"     type="boolean">`true` для фьючерсов и других специальных рынков.</ResponseField>
    <ResponseField name="participants"   type="array">Массив из двух элементов `[away, home]`. Каждый участник имеет `id`, `longName`, `shortName`, `homeAway`, `mainPitcher`, `rotationNumber`, `futuresSide`.</ResponseField>
  </Expandable>
</ResponseField>
