---
title: 'Получить среднюю цену'
description: 'Лучшие и средние цены по каждой игре лиги'
openapi: 'GET /exchange/getOddsForAveragePrice'
---

Возвращает усечённый список лучших и средних цен по каждой игре лиги. Для каждой игры и каждого рынка (moneyline — ставка на победителя / spread — фора / total — тотал) ответ включает:

- **лучшую цену** (цену верхнего ожидающего предложения);
- **среднюю цену**, которую вы заплатили бы, забирая не менее **$500** ликвидности;
- **максимальную ставку**, которая могла бы быть исполнена по лучшей цене и по средней цене.

Массивы по рынкам (`awayMoneylines`, `homeMoneylines` и т. д.) из каждой игры вырезаны; остаётся только сводный блок `odds`.

<Note>
В отличие от большинства эндпоинтов, этот возвращает игры на **верхнем уровне** (не под `data`).
</Note>

## Запрос {#request}

`GET /exchange/getOddsForAveragePrice`

<ParamField query="leagueRequested" type="string" required>
  Код лиги (нечувствителен к регистру).
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getOddsForAveragePrice?leagueRequested=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>
