Возвращает общий объём сведённых ставок по всему сайту за включительный диапазон **календарных дней по времени восточного побережья США (ET)**.

## Как вычисляется объём {#how-volume-is-calculated}

Каждая сведённая ставка вносит суммы ставок **обеих сторон** сделки:

- **ставка taker** (сведённая сумма), плюс
- **ставка maker**, выводимая из коэффициентов taker: при положительных коэффициентах taker это `stake × odds / 100`, при отрицательных — `stake × −100 / odds`.

Эквивалентно, с точки зрения любой из сторон каждая сведённая ставка вносит **`risk + win`** — вашу ставку плюс вашу потенциальную прибыль, потому что ваша потенциальная прибыль — это в точности ставка контрагента. Взятие $100 по +150 считается как $250 объёма ($100 со стороны taker + $150 со стороны maker).

<Note>
Объём использует сырые суммы ставок до комиссии. В полях `risk` / `win` из [Получить сведённые ставки](/ru/pages/rest/user/get-matched-bets) комиссия уже учтена, поэтому их сумма будет немного отличаться от этого эндпоинта.
</Note>

## Свежесть данных {#freshness}

Завершившиеся дни ET читаются из финализированного дневного архива. Если диапазон заканчивается сегодня (`endDate` позже сегодняшнего дня усекается до сегодня), сверху добавляется живой агрегат сегодняшних сведений, поэтому доля текущего дня обновляется в реальном времени по мере сведения ставок.

## Запрос {#request}

`GET /exchange/getMatchedVolume`

<ParamField query="startDate" type="string" required>
  Первый календарный день ET диапазона, `YYYY-MM-DD` (включительно).
</ParamField>

<ParamField query="endDate" type="string" required>
  Последний календарный день ET диапазона, `YYYY-MM-DD` (включительно). Не должен быть раньше `startDate`. Даты позже сегодняшней усекаются до сегодня.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getMatchedVolume?startDate=2026-08-10&endDate=2026-08-11" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Ответ {#response}

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="startDate" type="string">Эхо запрошенной начальной даты.</ResponseField>
    <ResponseField name="endDate" type="string">Эхо запрошенной конечной даты (до усечения).</ResponseField>
    <ResponseField name="matchedVolume" type="number">Общий сведённый объём в USD: сумма ставок обеих сторон (risk + win) каждой ставки, сведённой в диапазоне.</ResponseField>
  </Expandable>
</ResponseField>

```json Пример ответа
{
  "data": {
    "startDate": "2026-08-10",
    "endDate": "2026-08-11",
    "matchedVolume": 6447933.012757301
  }
}
```

## Лимиты частоты {#rate-limits}

Отдельного лимита для этого эндпоинта нет — действует только [глобальный лимит на IP](/ru/pages/rest/introduction#rate-limiting) (3,000 запросов на скользящую минуту). Для дашбордов опрос раз в несколько секунд — более чем достаточно; учтите, что финализированные дни никогда не меняются, поэтому повторный опрос имеет смысл только для диапазонов, включающих сегодня.

## Ошибки {#errors}

| Статус | Значение |
|---|---|
| `400` | Отсутствует или некорректен `startDate` / `endDate` (должно быть `YYYY-MM-DD`), либо `startDate` позже `endDate`. |
| `401` | Отсутствующий или неверный token аутентификации. |
| `429` | Превышен глобальный лимит на IP. Учитывайте заголовок `Retry-After`. |
| `503` | Сработал серверный 15-секундный тайм-аут. Можно безопасно повторить. |
