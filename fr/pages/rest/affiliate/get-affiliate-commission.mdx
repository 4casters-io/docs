---
title: 'Récupérer la commission d''affiliation'
description: 'Commission qui vous est versée par les joueurs que vous avez invités'
openapi: 'GET /affiliate/getAffiliateCommission'
---

Renvoie la commission versée à l'appelant par les joueurs qu'il a invités, groupée par nom d'utilisateur de joueur. Sans paramètre, renvoie les gains cumulés depuis l'origine ; avec `fromDate` / `toDate`, restreint la plage.

<Note>
Contrairement à la plupart des endpoints, celui-ci renvoie le résultat au **niveau supérieur** sous `commissionPaid` (pas sous `data`).
</Note>

## Requête {#request}

`GET /affiliate/getAffiliateCommission`

<ParamField query="fromDate" type="string">
  Date de début (`MM-DD-YYYY`). Par défaut `08-02-2021`.
</ParamField>
<ParamField query="toDate" type="string">
  Date de fin (`MM-DD-YYYY`). Par défaut aujourd'hui.
</ParamField>

<CodeGroup>
```bash curl (plage de dates)
curl "https://api.4casters.io/affiliate/getAffiliateCommission?fromDate=10-03-2022&toDate=10-10-2022" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (cumul total)
curl https://api.4casters.io/affiliate/getAffiliateCommission \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Réponse {#response}

<ResponseField name="commissionPaid" type="array">
  Chaque entrée est un objet à clé unique associant le nom d'utilisateur d'un joueur à la commission totale versée par ce joueur dans la plage demandée.
</ResponseField>

### Exemple {#example}

<CodeGroup>
```json JSON
{
  "commissionPaid": [
    { "alice":   124.50 },
    { "bob":      12.00 },
    { "charlie":  87.34 }
  ]
}
```
</CodeGroup>

## Erreurs {#errors}

| Statut | Signification |
| ------ | ------- |
| `400`  | `fromDate` n'est pas interprétable. |
