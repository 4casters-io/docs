---
title: 'Récupérer les ordres d''un match'
description: 'Lister vos ordres ouverts et paris matchés sur un seul match'
openapi: 'GET /user/getOrdersForGame'
---

Pour un id de match 4casters donné, renvoie les ordres ouverts et les paris matchés (non réglés) de l'appelant sur ce match. Les paris réglés ne sont pas renvoyés par cet endpoint — utilisez [Récupérer les wagers réglés](/fr/pages/rest/user/get-graded-wagers) pour ceux-là.

## Requête {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>Id de match 4casters.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Réponse {#response}

<ResponseField name="data.unmatched" type="array">
  Tableau des ordres ouverts sur le match, trié par heure de début de match croissante. Même format que [Récupérer les ordres non matchés](/fr/pages/rest/user/get-unmatched-orders).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Tableau des paris matchés (non réglés) sur le match. Même format que [Récupérer les paris matchés](/fr/pages/rest/user/get-matched-bets).
</ResponseField>

### Exemple {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## Erreurs {#errors}

| Statut | Signification |
| ------ | ------- |
| `404`  | `gameID` manquant ou pas un id de match valide. |
