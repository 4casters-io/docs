---
title: 'Annuler un ordre'
description: 'Annuler un seul ordre ouvert'
openapi: 'POST /session/cancel'
---

Annulez un seul ordre ouvert par id. Renvoie les montants non exécutés et exécutés au moment de l'annulation.

## Requête {#request}

`POST /session/cancel`

<ParamField body="sessionID" type="string" required>
  Id de l'ordre à annuler.
</ParamField>

<CodeGroup>
```bash curl
curl -X POST https://api.4casters.io/session/cancel \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sessionID": "65b036dfb31407c2b6bc1cfe"}'
```
</CodeGroup>

## Réponse {#response}

<ResponseField name="data" type="object">
  <Expandable title="CancelResult">
    <ResponseField name="success"      type="boolean" />
    <ResponseField name="sessionID"    type="string">Id de l'ordre annulé.</ResponseField>
    <ResponseField name="description"  type="string">Description lisible de l'ordre (par ex. `Lakers -3.5 -110`).</ResponseField>
    <ResponseField name="odds"         type="integer">Cotes américaines de l'ordre annulé.</ResponseField>
    <ResponseField name="filled"       type="number">Risque déjà matché au moment de l'annulation.</ResponseField>
    <ResponseField name="offered"      type="number" />
    <ResponseField name="remaining"    type="number">Risque encore non matché et désormais remboursé.</ResponseField>
    <ResponseField name="gameID"       type="string" />
    <ResponseField name="userReference" type="string" />
  </Expandable>
</ResponseField>

### Exemple {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "success": true,
    "sessionID": "65b036dfb31407c2b6bc1cfe",
    "description": "Lakers ML +125",
    "odds": 125,
    "filled": 0,
    "offered": 0,
    "remaining": 100,
    "gameID": "65f0c3c24ef07d0008abc123",
    "userReference": "my-order-1"
  }
}
```
</CodeGroup>

## Erreurs {#errors}

| Statut | Signification |
| ------ | ------- |
| `400`  | Id d'ordre invalide. |
| `403`  | Cet ordre n'est pas le vôtre. |
| `409`  | L'ordre n'a pas pu être annulé (par ex. déjà entièrement exécuté). |
