---
title: 'API de streaming da 4casters'
---

A API de streaming da 4casters entrega atualizações de usuário e de mercado em tempo real por uma conexão WebSocket crua.

## Endpoints {#endpoints}
- **Feed de usuário**: `wss://streaming-api.4casters.io/v2/user`
- **Feed de preços**: `wss://streaming-api.4casters.io/price-stream`

O feed de preços difunde todas as atualizações de mercado por padrão. Os clientes podem restringir o stream a eventos, ligas ou esportes específicos: consulte [Inscrições](/pt-BR/pages/streaming/price-feed#subscriptions).

## Autenticação {#auth}

Ambos os feeds se autenticam com um token da 4Casters. Envie o token no
cabeçalho `Authorization` do handshake WebSocket. O servidor deriva o usuário
a partir do token: **sem nome de usuário na URL**.

### Obter um token {#get-a-token}

Não há uma chave de API separada. Faça login com seu nome de usuário e senha
da 4Casters chamando o endpoint `/user/login` da API REST da 4Casters. A resposta
inclui um token que você pode usar aqui. Consulte [Autenticação](/pt-BR/pages/authentication)
para o tempo de vida e a rotação do token.

Consulte [`POST /user/login` na documentação da API REST da 4Casters](/pt-BR/pages/rest/authentication).

### Conectar {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const token = process.env.FOURCASTERS_TOKEN;
const ws = new WebSocket('wss://streaming-api.4casters.io/v2/user', {
  headers: { Authorization: token },
});
```
</CodeGroup>
