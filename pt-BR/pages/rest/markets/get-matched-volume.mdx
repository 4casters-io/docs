Retorna o volume total correspondido em todo o site para um intervalo inclusivo de **dias de calendário no horário US-Eastern (ET)**.

## Como o volume é calculado {#how-volume-is-calculated}

Toda aposta correspondida contribui com os valores apostados de **ambos os lados** da correspondência:

- o **valor apostado do taker** (o valor correspondido), mais
- o **valor apostado do maker**, derivado das odds do taker — com odds de taker positivas é `stake × odds / 100`, com odds de taker negativas é `stake × −100 / odds`.

De forma equivalente, da perspectiva de qualquer uma das partes, cada aposta correspondida contribui com **`risk + win`** — o seu valor apostado mais o seu lucro potencial, porque o seu lucro potencial é exatamente o valor apostado da contraparte. Um take de $100 a +150 conta como $250 de volume ($100 do lado taker + $150 do lado maker).

<Note>
O volume usa os valores apostados brutos, antes da comissão. Os campos `risk` / `win` de [Obter apostas correspondidas](/pt-BR/pages/rest/user/get-matched-bets) já embutem a comissão, então somá-los vai diferir ligeiramente deste endpoint.
</Note>

## Atualidade {#freshness}

Dias ET encerrados são lidos de um arquivo diário finalizado. Se o intervalo termina hoje (um `endDate` além de hoje é limitado a hoje), um agregado ao vivo das correspondências de hoje é somado por cima, então a parcela do dia atual atualiza em tempo real conforme as apostas correspondem.

## Solicitação {#request}

`GET /exchange/getMatchedVolume`

<ParamField query="startDate" type="string" required>
  Primeiro dia de calendário ET do intervalo, `YYYY-MM-DD` (inclusivo).
</ParamField>

<ParamField query="endDate" type="string" required>
  Último dia de calendário ET do intervalo, `YYYY-MM-DD` (inclusivo). Não pode ser anterior a `startDate`. Datas após hoje são limitadas a hoje.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getMatchedVolume?startDate=2026-08-10&endDate=2026-08-11" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="startDate" type="string">Eco da data de início solicitada.</ResponseField>
    <ResponseField name="endDate" type="string">Eco da data de fim solicitada (antes de ser limitada).</ResponseField>
    <ResponseField name="matchedVolume" type="number">Volume total correspondido em USD: a soma dos valores apostados de ambos os lados (risco + ganho) de cada aposta correspondida no intervalo.</ResponseField>
  </Expandable>
</ResponseField>

```json Exemplo de resposta
{
  "data": {
    "startDate": "2026-08-10",
    "endDate": "2026-08-11",
    "matchedVolume": 6447933.012757301
  }
}
```

## Limites de taxa {#rate-limits}

Não há limite específico deste endpoint — apenas o [limite global por IP](/pt-BR/pages/rest/introduction#rate-limiting) (3,000 requisições por minuto móvel) se aplica. Para dashboards, fazer polling a cada poucos segundos é mais do que suficiente; note que dias finalizados nunca mudam, então apenas intervalos que incluem hoje se beneficiam de repetir o polling.

## Erros {#errors}

| Status | Significado |
|---|---|
| `400` | `startDate` / `endDate` ausente ou malformado (deve ser `YYYY-MM-DD`), ou `startDate` depois de `endDate`. |
| `401` | Token de autenticação ausente ou inválido. |
| `429` | Limite global de taxa por IP excedido. Honre o cabeçalho `Retry-After`. |
| `503` | O timeout de 15 segundos do servidor foi atingido. Seguro para nova tentativa. |
