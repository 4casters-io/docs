---
title: 'Obter ligas'
description: 'Liste as ligas com mercados ativos'
openapi: 'GET /exchange/getLeagues'
---

Retorna todas as ligas com mercados ativos na exchange. Use os códigos de liga deste endpoint para buscar jogos (`/exchange/v2/getGames`) e livros de ofertas (`/exchange/v2/getOrderbook`).

Se a resposta contiver um nome de liga com `LIVE` (que não seja uma das ligas ao vivo por esporte `NFL-LIVE`, `NBA-LIVE`, `NCAAF-LIVE`, `NCAAB-LIVE`), o valor `"LIVE"` é acrescentado como um alias para "todos os jogos ao vivo".

## Solicitação {#request}

`GET /exchange/getLeagues`

<ParamField query="sport" type="string">
  Filtro opcional de esporte (`basketball`, `baseball`, `hockey`, `football`, `soccer`, `golf`, `tennis`, `mma`, etc.). Quando `sport=soccer` ou `sport=golf`, o valor `"all"` é acrescentado à lista.
</ParamField>

<CodeGroup>
```bash curl
curl https://api.4casters.io/exchange/getLeagues \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data.availableLeagues" type="array">
  Array de códigos de liga.
</ResponseField>

### Exemplo {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "availableLeagues": [
      "CHAMPIONS-LEAGUE",
      "NBA",
      "NHL",
      "BUNDESLIGA",
      "PREMIER-LEAGUE",
      "PGA",
      "LA-LIGA",

      "SERIE-A",
      "MLS",
      "UFCMMA"
    ]
  }
}
```
</CodeGroup>
