---
title: 'Obter aposta por ID'
description: 'Consulte uma única aposta por id ou id de transação'

---

Consulte uma única aposta (correspondida, liquidada ou oferta em aberto) pertencente a quem chama. Passe **ou** `id` **ou** `txID`, não ambos.

## Solicitação {#request}

`GET /user/getBetByID`

<ParamField query="id" type="string">
  `id` da aposta vindo de um endpoint de listagem como `/user/getMatchedBets`.
</ParamField>
<ParamField query="txID" type="string">
  Id de transação, ex.: o `wagerRequestID` ou `txID` retornado por `/session/v3/place`.
</ParamField>

Você deve passar exatamente um entre `id` e `txID`.

<CodeGroup>
```bash curl (por txID)
curl "https://api.4casters.io/user/getBetByID?txID=64824b329556daa319747e31" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (por id)
curl "https://api.4casters.io/user/getBetByID?id=6494ca85c9346058f35b2b1e" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

O formato de `bet` depende do estado atual da aposta:

- Uma aposta **liquidada** retorna o formato [GradedWager](/pt-BR/pages/rest/user/get-graded-wagers#response), incluindo `risk`, `win`, `fee` e `result`.
- Uma aposta **correspondida** retorna o formato [MatchedBet](/pt-BR/pages/rest/user/get-matched-bets#response).
- Uma **oferta em aberto** retorna o formato [UnmatchedOrder](/pt-BR/pages/rest/user/get-unmatched-orders#response).

Note que, ao contrário da maioria dos endpoints, este retorna a aposta no **nível superior** (não sob `data`).

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `400`  | Tanto `id` quanto `txID` ausentes, ou nenhuma aposta encontrada para o identificador fornecido. |
