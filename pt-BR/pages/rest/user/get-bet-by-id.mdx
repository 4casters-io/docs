---
title: 'Obter aposta por ID'
description: 'Consulta uma única aposta por id ou id de transação'
openapi: 'GET /user/getBetByID'
---

Consulta uma única aposta (casada, liquidada ou oferta aberta) que pertence à conta autenticada. Passe **ou** `id` **ou** `txID`, não ambos.

## Requisição {#request}

`GET /user/getBetByID`

<ParamField query="id" type="string">
  `id` da aposta de um endpoint de listagem como `/user/getMatchedBets`.
</ParamField>
<ParamField query="txID" type="string">
  Id de transação, p. ex. o `wagerRequestID` ou `txID` que `/session/v3/place` retorna.
</ParamField>

Você deve passar exatamente um de `id` ou `txID`.

<CodeGroup>
```bash curl (por txID)
curl "https://api.4casters.io/user/getBetByID?txID=64824b329556daa319747e31" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (por id)
curl "https://api.4casters.io/user/getBetByID?id=6494ca85c9346058f35b2b1e" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

A forma de `bet` depende do estado atual da aposta:

- Uma aposta **liquidada** retorna a forma [GradedWager](/pt-BR/pages/rest/user/get-graded-wagers#response), incluindo `risk`, `win`, `fee` e `result`.
- Uma aposta **casada** retorna a forma [MatchedBet](/pt-BR/pages/rest/user/get-matched-bets#response).
- Uma **oferta aberta** retorna a forma [UnmatchedOrder](/pt-BR/pages/rest/user/get-unmatched-orders#response).

Observe que, ao contrário da maioria dos endpoints, este retorna a aposta no **nível superior** (não sob `data`).

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `400`  | Faltam tanto `id` quanto `txID`, ou nenhuma aposta foi encontrada para o identificador indicado. |
