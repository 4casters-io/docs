---
title: 'Obter aposta por referência de usuário'
description: 'Consulta cada aposta ligada a um identificador definido pelo cliente'
openapi: 'GET /user/getBetByUserReference'
---

Consulta cada aposta ligada a um `userReference`. `userReference` é uma string opcional definida pelo cliente que você pode anexar a uma ordem ao enviá-la para rastreá-la do seu lado: este endpoint é a contraparte de leitura.

A resposta separa os resultados em três grupos:

- `unmatched` — ofertas abertas desta referência que ainda estão no livro.
- `matched`   — apostas casadas (não liquidadas) desta referência.
- `graded`    — apostas liquidadas desta referência, incluindo `risk`, `win`, `fee` e `result`.

## Requisição {#request}

`GET /user/getBetByUserReference`

<ParamField query="userReference" type="string" required>
  Referência definida pelo cliente, passada no momento do envio.
</ParamField>
<ParamField query="gameID" type="string" required>
  Limita a consulta a um único evento.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getBetByUserReference?userReference=my-order-1&gameID=67d1c942215edc7ee0c806ef" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data.unmatched" type="array">
  Ordens abertas — mesma forma de [Obter ordens não casadas](/pt-BR/pages/rest/user/get-unmatched-orders#response).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Apostas casadas (não liquidadas) — mesma forma de [Obter apostas casadas](/pt-BR/pages/rest/user/get-matched-bets#response).
</ResponseField>
<ResponseField name="data.graded" type="array">
  Apostas liquidadas — mesma forma de [Obter apostas liquidadas](/pt-BR/pages/rest/user/get-graded-wagers#response).
</ResponseField>

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `408`  | Falta `userReference` ou `gameID`. |
