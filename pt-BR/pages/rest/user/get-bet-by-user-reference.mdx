---
title: 'Obter aposta por referência do usuário'
description: 'Consulte todas as apostas vinculadas a um identificador definido pelo cliente'
openapi: 'GET /user/getBetByUserReference'
---

Consulte todas as apostas vinculadas a um `userReference`. `userReference` é uma string opcional definida pelo cliente que você pode anexar a uma ordem no momento do envio para rastreá-la do seu lado — este endpoint é a contraparte de leitura.

A resposta separa os resultados em três grupos:

- `unmatched` — ofertas em aberto desta referência que ainda estão em espera no livro.
- `matched`   — apostas correspondidas (não liquidadas) desta referência.
- `graded`    — apostas liquidadas desta referência, incluindo `risk`, `win`, `fee` e `result`.

## Solicitação {#request}

`GET /user/getBetByUserReference`

<ParamField query="userReference" type="string" required>
  Referência definida pelo cliente, passada no momento do envio.
</ParamField>
<ParamField query="gameID" type="string" required>
  Restringe a consulta a um único jogo.
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getBetByUserReference?userReference=my-order-1&gameID=67d1c942215edc7ee0c806ef" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data.unmatched" type="array">
  Ordens em aberto — mesmo formato de [Obter ordens não correspondidas](/pt-BR/pages/rest/user/get-unmatched-orders#response).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Apostas correspondidas (não liquidadas) — mesmo formato de [Obter apostas correspondidas](/pt-BR/pages/rest/user/get-matched-bets#response).
</ResponseField>
<ResponseField name="data.graded" type="array">
  Apostas liquidadas — mesmo formato de [Obter apostas liquidadas](/pt-BR/pages/rest/user/get-graded-wagers#response).
</ResponseField>

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `408`  | `userReference` ou `gameID` ausente. |
