---
title: 'Heartbeat de ordens'
description: 'Cancela automaticamente suas ordens se o seu cliente se desconectar'
openapi: 'POST /user/ordersHeartbeat'
---

Um mecanismo de segurança: envie um heartbeat com um `timeout` (em segundos). Se o próximo heartbeat não for recebido em `timeout` segundos, **todas as suas ordens abertas são canceladas**.

Use este endpoint em qualquer cliente que envie ordens em aberto: se o seu processo cair ou perder conectividade, o heartbeat garante que as ordens obsoletas sejam retiradas em vez de ficarem no livro.

## Requisição {#request}

`POST /user/ordersHeartbeat`

<ParamField body="timeout" type="integer" required>
  Timeout de cancelamento, em segundos. Deve ser maior que `5`.
</ParamField>

<CodeGroup>
```bash curl
curl -X POST https://api.4casters.io/user/ordersHeartbeat \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"timeout": 30}'
```

```json Corpo JSON
{ "timeout": 30 }
```
</CodeGroup>

## Resposta {#response}

A resposta é repassada a partir do serviço de ordens:

```json
{ "data": { /* heartbeat ack payload */ } }
```

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `400`  | `timeout` falta, não é um número ou é `<= 5`. |
| `503`  | O serviço de ordens não está disponível. |
