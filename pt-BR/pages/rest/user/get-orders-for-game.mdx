---
title: 'Obter ordens de um jogo'
description: 'Liste suas ordens em aberto e apostas correspondidas em um único jogo'
openapi: 'GET /user/getOrdersForGame'
---

Para um dado id de jogo da 4casters, retorna as ordens em aberto e as apostas correspondidas (não liquidadas) de quem chama para esse jogo. Apostas liquidadas não são retornadas por este endpoint — use [Obter apostas liquidadas](/pt-BR/pages/rest/user/get-graded-wagers) para elas.

## Solicitação {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>Id de jogo da 4casters.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="data.unmatched" type="array">
  Array de ordens em aberto no jogo, ordenado de forma crescente pelo horário de início do jogo. Mesmo formato de [Obter ordens não correspondidas](/pt-BR/pages/rest/user/get-unmatched-orders).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Array de apostas correspondidas (não liquidadas) no jogo. Mesmo formato de [Obter apostas correspondidas](/pt-BR/pages/rest/user/get-matched-bets).
</ResponseField>

### Exemplo {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `404`  | `gameID` ausente ou não é um id de jogo válido. |
