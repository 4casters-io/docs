---
title: 'Obter comissão de afiliado'
description: 'Comissão que os jogadores que você convidou pagam a você'
openapi: 'GET /affiliate/getAffiliateCommission'
---

Retorna a comissão paga à conta autenticada pelos jogadores que ela convidou, agrupada por nome de usuário do jogador. Sem parâmetros, retorna os ganhos de toda a vida; com `fromDate` / `toDate`, restringe o intervalo.

<Note>
Ao contrário da maioria dos endpoints, este retorna o resultado no **nível superior** como `commissionPaid` (não sob `data`).
</Note>

## Requisição {#request}

`GET /affiliate/getAffiliateCommission`

<ParamField query="fromDate" type="string">
  Data de início (`MM-DD-YYYY`). O valor padrão é `08-02-2021`.
</ParamField>
<ParamField query="toDate" type="string">
  Data de fim (`MM-DD-YYYY`). O valor padrão é hoje.
</ParamField>

<CodeGroup>
```bash curl (intervalo de datas)
curl "https://api.4casters.io/affiliate/getAffiliateCommission?fromDate=10-03-2022&toDate=10-10-2022" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (vitalício)
curl https://api.4casters.io/affiliate/getAffiliateCommission \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Resposta {#response}

<ResponseField name="commissionPaid" type="array">
  Cada entrada é um objeto de uma única chave que mapeia o nome de usuário de um jogador para a comissão total paga por esse jogador no intervalo solicitado.
</ResponseField>

### Exemplo {#example}

<CodeGroup>
```json JSON
{
  "commissionPaid": [
    { "alice":   124.50 },
    { "bob":      12.00 },
    { "charlie":  87.34 }
  ]
}
```
</CodeGroup>

## Erros {#errors}

| Status | Significado |
| ------ | ------- |
| `400`  | `fromDate` não pode ser interpretado. |
