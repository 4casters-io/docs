---
title: 'Cancelando ordens'
---

Quatro variantes de cancelamento são suportadas. Todas respondem com o mesmo envelope: `{ requestID, data: [ ...CancelResponsePayload ] }`.

## Payload da resposta de cancelamento {#cancel-response-payload}

Todo cancelamento bem-sucedido retorna uma ou mais entradas neste formato. Note que a capitalização dos nomes de campo muda entre a requisição (`orderId`/`gameId`, `d` minúsculo) e a resposta (`orderID`/`gameID`, `ID` maiúsculo).

<CodeGroup>
```json JSON
{
  "success": true,
  "orderID": "67f45377c18c6697c172afa4",
  "odds": -110,
  "filled": 0,
  "offered": 100,
  "remaining": 100,
  "side": "5c12bc1ce0daba000f47ba8b",
  "number": -3.5,
  "gameID": "688c0516fbc14da0c202d426",
  "userReference": "client-ref-001",
  "description": "Dallas Mavericks +3.5"
}
```
</CodeGroup>

<ResponseField name="success" type="boolean">
  `true` quando a ordem foi cancelada.
</ResponseField>
<ResponseField name="orderID" type="string">
  ID da ordem cancelada.
</ResponseField>
<ResponseField name="filled" type="number">
  Valor que já havia sido correspondido antes de o cancelamento chegar.
</ResponseField>
<ResponseField name="offered" type="number">
  Sempre `0` após um cancelamento — o lado ofertado é reduzido a zero.
</ResponseField>
<ResponseField name="remaining" type="number">
  Valor que estava sem correspondência no momento do cancelamento.
</ResponseField>
<ResponseField name="odds" type="number">
  Odds da ordem cancelada em formato americano, da perspectiva do maker.
</ResponseField>
<ResponseField name="side" type="string">
  ID do participante (moneyline/spread) ou `over`/`under` (totais).
</ResponseField>
<ResponseField name="number" type="number">
  Número do spread ou do total; `null` para moneylines.
</ResponseField>
<ResponseField name="gameID" type="string">
  Jogo em que a ordem cancelada estava.
</ResponseField>
<ResponseField name="userReference" type="string">
  O `userReference` que você definiu ao enviar a ordem, se houver.
</ResponseField>
<ResponseField name="description" type="string">
  Descrição legível da aposta (ex.: `"Dallas Mavericks +3.5"`).
</ResponseField>

## Cancelar por ID {#cancel-by-id}

Cancele uma única ordem pelo seu ID de ordem.

### Solicitação {#request}

<CodeGroup>
```json JSON
[
  "cancelById",
  {
    "requestID": "YOUR_REQUEST_ID",
    "orderId": "ORDER_ID_TO_CANCEL"
  }
]
```
</CodeGroup>

### Resposta {#response}

<CodeGroup>
```json JSON
{
  "requestID": "YOUR_REQUEST_ID",
  "data": [
    {
      "success": true,
      "orderID": "67f45377c18c6697c172afa4",
      "odds": -110,
      "filled": 0,
      "offered": 0,
      "remaining": 100,
      "side": "5c12bc1ce0daba000f47ba8b",
      "number": -3.5,
      "gameID": "688c0516fbc14da0c202d426",
      "userReference": "client-ref-001",
      "description": "Dallas Mavericks +3.5"
    }
  ]
}
```
</CodeGroup>

## Cancelar várias {#cancel-multiple}

Cancele um conjunto específico de ordens por ID.

### Solicitação {#request-2}

<CodeGroup>
```json JSON
[
  "cancelMultiple",
  {
    "requestID": "YOUR_REQUEST_ID",
    "orderIDs": [
      "ORDER_ID_1",
      "ORDER_ID_2",
      "ORDER_ID_3"
    ]
  }
]
```
</CodeGroup>

### Resposta {#response-2}

`data` contém uma entrada por ID de ordem; verifique cada flag `success`.

<CodeGroup>
```json JSON
{
  "requestID": "YOUR_REQUEST_ID",
  "data": [
    {
      "success": true,
      "orderID": "ORDER_ID_1",
      "odds": -110,
      "filled": 0,
      "offered": 0,
      "remaining": 100,
      "side": "5c12bc1ce0daba000f47ba8b",
      "number": -3.5,
      "gameID": "688c0516fbc14da0c202d426",
      "userReference": "",
      "description": "Dallas Mavericks +3.5"
    },
    {
      "success": false,
      "orderID": "ORDER_ID_2",
      "description": "order already cancelled"
    }
  ]
}
```
</CodeGroup>

## Cancelar todas por jogo {#cancel-all-by-game}

Cancele todas as ordens em aberto que você tem em um único jogo. Opcionalmente, restrinja o cancelamento a um mercado específico passando `type`, `side` e/ou `market`.

### Solicitação {#request-3}

<CodeGroup>
```json JSON
[
  "cancelAllByGame",
  {
    "requestID": "YOUR_REQUEST_ID",
    "gameId": "GAME_ID_TO_CANCEL",
    "type": "spread",
    "side": "5c12bc1ce0daba000f47ba8b",
    "market": "main"
  }
]
```
</CodeGroup>

<ResponseField name="gameId" type="string" required>
  Jogo cujas ordens devem ser canceladas.
</ResponseField>
<ResponseField name="type" type="string">
  Opcional — filtra para um único tipo de mercado: `moneyline`, `spread`, `total` ou `moneyline1x2`.
</ResponseField>
<ResponseField name="side" type="string">
  Opcional — ID do participante (moneyline/spread) ou `over`/`under` (totais).
</ResponseField>
<ResponseField name="market" type="string">
  Opcional — identificador do mercado (ex.: `main`).
</ResponseField>

### Resposta {#response-3}

<CodeGroup>
```json JSON
{
  "requestID": "YOUR_REQUEST_ID",
  "data": [
    {
      "success": true,
      "orderID": "67f45377c18c6697c172afa4",
      "odds": -110,
      "filled": 0,
      "offered": 0,
      "remaining": 100,
      "side": "5c12bc1ce0daba000f47ba8b",
      "number": -3.5,
      "gameID": "688c0516fbc14da0c202d426",
      "userReference": "",
      "description": "Dallas Mavericks +3.5"
    }
  ]
}
```
</CodeGroup>

## Erros {#errors}

Quando um cancelamento não pode ser processado, o servidor responde com o envelope de erro padrão (sem campo `data`):

<CodeGroup>
```json JSON
{
  "requestID": "YOUR_REQUEST_ID",
  "error": "order not found"
}
```
</CodeGroup>

Valores comuns de `error`:

| Erro | Quando |
| --- | --- |
| `invalid order ID format` | O `orderId` de `cancelById` não é um ObjectID válido. |
| `order not found` | O ID da ordem não existe. |
| `unauthorized: order does not belong to user` | Você está tentando cancelar a ordem de outro usuário. |
| `order already cancelled` | A ordem já havia sido cancelada. |
| `order is expired` | A ordem expirou antes de o cancelamento chegar. |
| `order already graded` | A ordem já foi avaliada (liquidada). |
| `game not found` | O jogo referenciado não está no cache. |
| `Failed to process cancelMultiple` | Erro inesperado ao processar um lote `cancelMultiple`. |
| `Failed to process cancelAll` | Erro inesperado ao processar `cancelAll`. |
| `Failed to process cancelAllByGame` | Erro inesperado ao processar `cancelAllByGame`. |

Para cancelamentos em lote (`cancelMultiple`, `cancelAllByGame`, `cancelAll`), falhas por ordem aparecem em `data` com `success: false` e uma `description` explicando o motivo — apenas um `error` no nível do envelope indica que a requisição inteira falhou.
