---
title: '獲取參賽方'
description: '列出球隊、球員和期貨盤方向'
openapi: 'GET /exchange/getParticipants'
---

回傳交易所範圍內去重後的參賽方列表 — 球隊、球員、期貨盤方向。下 `moneyline` 或 `spread` 訂單時，將此端點的 `participantID` 值用作 `side` 欄位。

## 請求 {#request}

`GET /exchange/getParticipants`

<ParamField query="active" type="string">
  當 `active=true` 時，將回應限定為未來開賽賽事的參賽方。當 `active=false`（或省略）時，回傳所有賽事的參賽方。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getParticipants?active=true" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 回應 {#response}

<ResponseField name="data.participants" type="array">
  <Expandable title="Participant">
    <ResponseField name="participantID" type="string">參賽方 ID。下單勝盤 / 讓分訂單時用作 `side`。</ResponseField>
    <ResponseField name="longName"      type="string" />
    <ResponseField name="shortName"     type="string" />
    <ResponseField name="league"        type="string" />
    <ResponseField name="sport"         type="string" />
  </Expandable>
</ResponseField>

### 示例 {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "participants": [
      {
        "participantID": "6021801d14a2fe0012fa0c62",

      }
    ]
  }

```
</CodeGroup>
