---
title: '獲取賽事'
description: '列出某聯賽的活躍賽事'
openapi: 'GET /exchange/v2/getGames'
---

回傳某聯賽的全部活躍賽事。回應**不**包含訂單簿或任何價格 — 請呼叫 [獲取訂單簿](/zh-Hant/pages/rest/markets/get-orderbook) 獲取。

## 請求 {#request}

`GET /exchange/v2/getGames`

<ParamField query="league" type="string" required>
  來自 [獲取聯賽](/zh-Hant/pages/rest/markets/get-leagues) 的聯賽代碼。使用特殊值 `upcoming` 可獲取跨聯賽的全部即將開賽賽事。
</ParamField>
<ParamField query="sport" type="string">
  可選的運動項目過濾。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/v2/getGames?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 回應 {#response}

<ResponseField name="data.games" type="array">
  <Expandable title="Game">
    <ResponseField name="id"             type="string">賽事 ID。</ResponseField>
    <ResponseField name="parentGameID"   type="string">父賽事 ID（若這是子市場：附加盤、分段盤）。</ResponseField>
    <ResponseField name="cheapDataUID"   type="string">賽事的穩定跨系統識別碼（用於盤口關聯）。</ResponseField>
    <ResponseField name="league"         type="string" />
    <ResponseField name="sport"          type="string" />
    <ResponseField name="start"          type="string">ISO 8601 開賽時間。</ResponseField>
    <ResponseField name="ended"          type="boolean" />
    <ResponseField name="live"           type="boolean" />
    <ResponseField name="featured"       type="boolean" />
    <ResponseField name="eventName"      type="string" />
    <ResponseField name="tournamentName" type="string" />
    <ResponseField name="periodName"     type="string">例如 `Full Time`、`1H`、`Set 1`。</ResponseField>
    <ResponseField name="isSpecials"     type="boolean">期貨盤及其他特殊盤為 `true`。</ResponseField>
    <ResponseField name="participants"   type="array">二元 `[away, home]` 陣列。每個參賽方有 `id`、`longName`、`shortName`、`homeAway`、`mainPitcher`、`rotationNumber`、`futuresSide`。</ResponseField>
  </Expandable>
</ResponseField>
