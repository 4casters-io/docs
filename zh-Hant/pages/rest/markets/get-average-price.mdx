---
title: '獲取均價'
description: '某聯賽中每場賽事的最優價與均價'
openapi: 'GET /exchange/getOddsForAveragePrice'
---

回傳某聯賽中每場賽事的最優價與均價的截斷列表。對每場賽事和每個市場（moneyline / spread / total），回應包含：

- **最優價格**（最優掛單上的價格）；
- 掃掉至少 **$500** 流動性時你會支付的**均價**；
- 可按最優價格和均價成交的**最大投注額**。

每個賽事上的按市場陣列（`awayMoneylines`、`homeMoneylines` 等）已被剝離；僅保留彙總的 `odds` 塊。

<Note>
與大多數端點不同，此端點在**頂層**回傳賽事（不在 `data` 下）。
</Note>

## 請求 {#request}

`GET /exchange/getOddsForAveragePrice`

<ParamField query="leagueRequested" type="string" required>
  聯賽代碼（不區分大小寫）。
</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/exchange/getOddsForAveragePrice?leagueRequested=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>
