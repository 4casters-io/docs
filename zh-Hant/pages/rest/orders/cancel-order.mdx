---
title: '取消一筆訂單'
description: '取消單筆未成交訂單'
openapi: 'POST /session/cancel'
---

按 ID 取消單筆未成交訂單。返回取消時的未成交額和已成交額。

## 請求 {#request}

`POST /session/cancel`

<ParamField body="sessionID" type="string" required>
  要取消的訂單 ID。
</ParamField>

<CodeGroup>
```bash curl
curl -X POST https://api.4casters.io/session/cancel \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sessionID": "65b036dfb31407c2b6bc1cfe"}'
```
</CodeGroup>

## 響應 {#response}

<ResponseField name="data" type="object">
  <Expandable title="CancelResult">
    <ResponseField name="success"      type="boolean" />
    <ResponseField name="sessionID"    type="string">被取消的訂單 ID。</ResponseField>
    <ResponseField name="description"  type="string">可讀的訂單描述（例如 `Lakers -3.5 -110`）。</ResponseField>
    <ResponseField name="odds"         type="integer">被取消訂單的美式賠率。</ResponseField>
    <ResponseField name="filled"       type="number">取消時已被撮合的風險額。</ResponseField>
    <ResponseField name="offered"      type="number" />
    <ResponseField name="remaining"    type="number">當時仍未撮合、現已退回的風險額。</ResponseField>
    <ResponseField name="gameID"       type="string" />
    <ResponseField name="userReference" type="string" />
  </Expandable>
</ResponseField>

### 示例 {#example}

<CodeGroup>
```json JSON
{
  "data": {

```
</CodeGroup>

## 錯誤 {#errors}

| 狀態 | 含義 |
| ------ | ------- |
| `400`  | 無效的訂單 ID。 |
| `403`  | 不是你的訂單。 |
| `409`  | 訂單無法取消（例如已全部成交）。 |
