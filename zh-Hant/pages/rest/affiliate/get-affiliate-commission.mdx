---
title: '獲取聯盟佣金'
description: '你邀請的玩家向你支付的佣金'
openapi: 'GET /affiliate/getAffiliateCommission'
---

回傳呼叫方所邀請玩家向其支付的佣金，按玩家使用者名稱分組。不帶參數時回傳終身收益；帶 `fromDate` / `toDate` 時限定範圍。

<Note>
與大多數端點不同，此端點在**頂層**以 `commissionPaid` 回傳結果（不在 `data` 下）。
</Note>

## 請求 {#request}

`GET /affiliate/getAffiliateCommission`

<ParamField query="fromDate" type="string">
  開始日期（`MM-DD-YYYY`）。預設為 `08-02-2021`。
</ParamField>
<ParamField query="toDate" type="string">
  結束日期（`MM-DD-YYYY`）。預設為今天。
</ParamField>

<CodeGroup>
```bash curl（日期範圍）
curl "https://api.4casters.io/affiliate/getAffiliateCommission?fromDate=10-03-2022&toDate=10-10-2022" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl（全部時間）
curl https://api.4casters.io/affiliate/getAffiliateCommission \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## 回應 {#response}

<ResponseField name="commissionPaid" type="array">
  每條記錄是單鍵物件，將玩家使用者名稱對應為該玩家在請求範圍內支付的佣金總額。
</ResponseField>

### 示例 {#example}

<CodeGroup>
```json JSON
{
  "commissionPaid": [
    { "alice":   124.50 },
    { "bob":      12.00 },
    { "charlie":  87.34 }
  ]
}
```
</CodeGroup>

## 錯誤 {#errors}

| 狀態 | 含義 |
| ------ | ------- |
| `400`  | `fromDate` 無法解析。 |
