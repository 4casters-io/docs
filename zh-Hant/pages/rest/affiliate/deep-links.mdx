---
title: '深度連結'
description: '把玩家直接帶到指定投注，並附帶你的推薦碼'
---

深度連結會開啟 4casters 首頁，並直接彈出你所選賽事、市場和方向的吃單視窗。加上你的推薦碼，透過該連結進入並註冊的玩家都會歸屬於你。

```
https://4casters.io/?game={gameID}&market=spread&side=away&line=3.5&ref=YOUR_CODE
```

無論訪客是否登入，連結都有效。未登入的訪客會看到該投注以及登入 / 註冊提示；推薦碼會記在其瀏覽器中，並在註冊頁面的表單裡自動填入。

## 構建連結 {#building-a-link}

從賽事 id 開始，它可以從 [`/exchange/getGames`](/zh-Hant/pages/rest/markets/get-games) 獲取，也可以從任意賽事頁面的位址列獲取（`/exchange-single/{gameID}`）。然後加上你想開啟的市場。

<ParamField query="game" type="string" required>
  賽事 id（24 位十六進位）。
</ParamField>
<ParamField query="market" type="string" required>
  `moneyline`、`spread`、`total` 或 `1x2`（足球三項市場）。
</ParamField>
<ParamField query="side" type="string" required>
  moneyline、spread 和 1x2 用 `home` 或 `away`。total 用 `over` 或 `under`。1x2 也接受 `draw`。
</ParamField>
<ParamField query="line" type="number">
  讓分或大小分數值，以所選方向的視角書寫。客隊 +3.5 是 `side=away&line=3.5`；主隊 -3.5 是 `side=home&line=-3.5`。省略則開啟主線。
</ParamField>
<ParamField query="pick" type="string">
  僅限 1x2：`yes`（預設）或 `no`。
</ParamField>
<ParamField query="ref" type="string">
  你的推薦碼，與 `/sign-up/{code}` 連結中使用的相同。
</ParamField>

## 示例 {#examples}

<CodeGroup>
```text 客隊 moneyline
https://4casters.io/?game=6a84db9c5ddbd1134524a222&market=moneyline&side=away&ref=YOUR_CODE
```

```text 主隊 -3.5
https://4casters.io/?game=6a84db9c5ddbd1134524a222&market=spread&side=home&line=-3.5&ref=YOUR_CODE
```

```text 主線大小分，under
https://4casters.io/?game=6a84db9c5ddbd1134524a222&market=total&side=under&ref=YOUR_CODE
```

```text 平局，三項
https://4casters.io/?game=6a84db9c5ddbd1134524a222&market=1x2&side=draw&ref=YOUR_CODE
```
</CodeGroup>

## 玩家看到什麼 {#what-the-player-sees}

連結指向的是一個市場，而不是某一筆訂單。頁面開啟時，視窗顯示該方向當前掛單中的最佳價格，以及其餘可選價格。價格會變動，所以玩家看到的數字可能與你構建連結時看到的不同；視窗始終顯示即時訂單簿，玩家在下注前確認價格。

如果當前沒有人在該方向報價，視窗會轉為在該線位建立報價而不是吃單，和在交易所點選空白單元格的行為一致。

## 說明 {#notes}

- **賽事會進入滾球。**比賽開始後，賽前市場關閉，另一個滾球市場開啟。開賽後再開啟的賽前連結會轉而開啟滾球市場的訂單簿。
- **未知線位。**如果連結中的線位不是該賽事擁有的（或省略了 `line` 而賽事尚未發布主線），首頁會開啟但不彈出視窗。絕不會悄悄把玩家換到另一條線。
- **推薦歸屬。**瀏覽器首次攜帶的推薦碼會一直保留到該訪客註冊為止。已有帳戶的訪客不會被重新歸屬。
- **賽事頁面同樣適用。**同一組 `market` / `side` / `line` / `ref` 參數在賽事頁面（`/exchange-single/{gameID}?market=...`）上也有效，會在該賽事的頁面上彈出視窗，而不是在首頁。
- **特項和球員市場**目前還不能用這些參數定位。
