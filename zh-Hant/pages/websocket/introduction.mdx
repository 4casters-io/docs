---
title: '4casters 訂單 API'
---

4casters 訂單 API 透過原始 WebSocket 連線支援即時下單、取消和會話管理。

## 端點 {#endpoints}
- **訂單 API**：`wss://orders-api.4casters.io/orders/ws`

## 認證 {#auth}

連線使用 4Casters 令牌進行認證。在 WebSocket 握手時於
`Authorization` 請求頭中傳送令牌。伺服器從令牌推導使用者
— **URL 中無需使用者名稱**。

### 獲取令牌 {#get-a-token}

使用你的 4Casters 使用者名稱和密碼，呼叫 4Casters REST API 的 `/user/login`
端點登入。響應中包含可在此處使用的令牌。

見 [4Casters REST API 文件中的 `POST /user/login`](/zh-Hant/pages/rest/authentication)。

### 連線 {#connect}

<CodeGroup>
```javascript JavaScript
const WebSocket = require('ws');
const token = process.env.FOURCASTERS_TOKEN;
const ws = new WebSocket('wss://orders-api.4casters.io/orders/ws', {
  headers: { Authorization: token },
});
```
</CodeGroup>

## 訊息格式 {#message-format}

每個客戶端請求都是二元組 `[messageType, payload]`。每個載荷都應包含你生成的 `requestID`；伺服器會原樣回傳，以便你關聯響應。

<CodeGroup>
```json 請求
[
  "messageType",
  {
    "requestID": "YOUR_REQUEST_ID",
    "...": "..."
  }
]
```
</CodeGroup>

伺服器響應是帶有 `requestID` 以及 `data`（成功）或 `error`（失敗）的 JSON 物件：

<CodeGroup>
```json 成功
{
  "requestID": "YOUR_REQUEST_ID",
  "data": { "...": "..." }
}
```

```json 錯誤
{
  "requestID": "YOUR_REQUEST_ID",
  "error": "human-readable error"
}
```
</CodeGroup>
