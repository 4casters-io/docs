---
title: 'Huidige gebruiker ophalen'
description: 'Het geauthenticeerde account lezen'
openapi: 'GET /user/getMe'
---

Geeft de accountinformatie van de momenteel geauthenticeerde gebruiker terug, waaronder saldo, kredietlimiet, actuele liability (je maximale verlies), standaard odds-formaat en toegangsvlaggen.

## Verzoek {#request}

`GET /user/getMe`

Dit endpoint heeft geen parameters. Authenticatie is vereist (zie [Authenticatie](/nl/pages/rest/authentication)).

<CodeGroup>
```bash curl
curl https://api.4casters.io/user/getMe \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>
