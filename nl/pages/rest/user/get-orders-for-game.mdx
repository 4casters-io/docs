---
title: 'Orders voor een wedstrijd ophalen'
description: 'Je openstaande orders en gematchte weddenschappen op één wedstrijd weergeven'
openapi: 'GET /user/getOrdersForGame'
---

Geeft voor een gegeven 4casters-wedstrijd-id de openstaande orders en gematchte (nog niet afgewikkelde) weddenschappen van de aanroeper op die wedstrijd terug. Afgewikkelde weddenschappen worden niet door dit endpoint teruggegeven — gebruik daarvoor [Afgewikkelde wagers ophalen](/nl/pages/rest/user/get-graded-wagers).

## Verzoek {#request}

`GET /user/getOrdersForGame`

<ParamField query="gameID" type="string" required>4casters-wedstrijd-id.</ParamField>

<CodeGroup>
```bash curl
curl "https://api.4casters.io/user/getOrdersForGame?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Antwoord {#response}

<ResponseField name="data.unmatched" type="array">
  Array van openstaande orders op de wedstrijd, oplopend gesorteerd op starttijd van de wedstrijd. Zelfde vorm als [Niet-gematchte orders ophalen](/nl/pages/rest/user/get-unmatched-orders).
</ResponseField>
<ResponseField name="data.matched" type="array">
  Array van gematchte (nog niet afgewikkelde) weddenschappen op de wedstrijd. Zelfde vorm als [Gematchte weddenschappen ophalen](/nl/pages/rest/user/get-matched-bets).
</ResponseField>

### Voorbeeld {#example}

<CodeGroup>
```json JSON
{
  "data": {
    "unmatched": [/* UnmatchedOrder, ... */],
    "matched":   [/* MatchedBet, ...     */]
  }
}
```
</CodeGroup>

## Fouten {#errors}

| Status | Betekenis |
| ------ | ------- |
| `404`  | `gameID` ontbreekt of is geen geldig wedstrijd-id. |
