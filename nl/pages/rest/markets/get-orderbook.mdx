Geeft het orderboek voor een competitie of één wedstrijd terug in **platte** vorm: elke markt is een array van orders in plaats van een object met spread / total als sleutel.

Dit is het aanbevolen orderboek-endpoint. Combineer het met de price feed van de [WebSocket Streaming](/nl/pages/streaming/price-feed) voor realtime updates.

## Verzoek {#request}

`GET /exchange/v2/getOrderbook`

<ParamField query="league" type="string">
  Competitiecode, bijv. `NBA` (hoofdletterongevoelig). Vereist wanneer `gameID` niet is meegegeven.
</ParamField>
<ParamField query="sport" type="string">
  Sportnaam, bijv. `basketball` (hoofdletterongevoelig). Optioneel filter wanneer `league` is gezet.
</ParamField>
<ParamField query="gameID" type="string">
  Id van één wedstrijd. Wanneer meegegeven, worden `league` en `sport` genegeerd.
</ParamField>

<CodeGroup>
```bash curl (één competitie)
curl "https://api.4casters.io/exchange/v2/getOrderbook?league=NBA" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (één wedstrijd)
curl "https://api.4casters.io/exchange/v2/getOrderbook?gameID=688c0516fbc14da0c202d426" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Antwoord {#response}

<ResponseField name="data.games" type="array">
  Elke `game` heeft de standaardvorm van [Game](/nl/pages/rest/markets/get-games#response) met de volgende extra arrays per markt:

  <Expandable title="Orderboekvelden per wedstrijd">
    <ResponseField name="awayMoneylines"    type="array">Openstaande moneyline-orders (inzet op de winnaar) op het uitteam. Gesorteerd op beste prijs eerst.</ResponseField>
    <ResponseField name="homeMoneylines"    type="array">Openstaande moneyline-orders op het thuisteam.</ResponseField>
    <ResponseField name="awaySpreads"       type="array">Openstaande spread-orders (handicap) aan de uitkant, platgeslagen over alle spread-getallen heen.</ResponseField>
    <ResponseField name="homeSpreads"       type="array">Openstaande spread-orders aan de thuiskant.</ResponseField>
    <ResponseField name="over"              type="array">Openstaande `over`-orders, platgeslagen over alle totals heen.</ResponseField>
    <ResponseField name="under"             type="array">Openstaande `under`-orders.</ResponseField>
    <ResponseField name="awayMoneylines1x2" type="array">**Alleen voetbal.** Driewegs-moneyline-orders op het uitteam.</ResponseField>
    <ResponseField name="homeMoneylines1x2" type="array">**Alleen voetbal.** Driewegs-moneyline-orders op het thuisteam.</ResponseField>
    <ResponseField name="draw1x2"           type="array">**Alleen voetbal.** Driewegs-moneyline-orders op het gelijkspel.</ResponseField>
    <ResponseField name="openInterest"      type="number">Som van `bet` over elke openstaande order op de wedstrijd.</ResponseField>
    <ResponseField name="matchedVolume"     type="number">Totaal gematcht volume op deze wedstrijd.</ResponseField>
  </Expandable>
</ResponseField>
