---
title: 'Affiliatecommissie ophalen'
description: 'Commissie die je uitgenodigde spelers aan jou hebben betaald'
openapi: 'GET /affiliate/getAffiliateCommission'
---

Geeft de commissie terug die de spelers die de aanroeper heeft uitgenodigd aan de aanroeper hebben betaald, gegroepeerd op gebruikersnaam van de speler. Zonder parameters worden de totale verdiensten over de hele levensduur teruggegeven; met `fromDate` / `toDate` beperk je het bereik.

<Note>
Anders dan de meeste endpoints geeft dit endpoint het resultaat op het **hoogste niveau** terug als `commissionPaid` (niet onder `data`).
</Note>

## Verzoek {#request}

`GET /affiliate/getAffiliateCommission`

<ParamField query="fromDate" type="string">
  Startdatum (`MM-DD-YYYY`). Standaard `08-02-2021`.
</ParamField>
<ParamField query="toDate" type="string">
  Einddatum (`MM-DD-YYYY`). Standaard vandaag.
</ParamField>

<CodeGroup>
```bash curl (datumbereik)
curl "https://api.4casters.io/affiliate/getAffiliateCommission?fromDate=10-03-2022&toDate=10-10-2022" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash curl (hele levensduur)
curl https://api.4casters.io/affiliate/getAffiliateCommission \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Antwoord {#response}

<ResponseField name="commissionPaid" type="array">
  Elke entry is een object met één sleutel dat de gebruikersnaam van een speler koppelt aan de totale commissie die die speler in het opgevraagde bereik heeft betaald.
</ResponseField>

### Voorbeeld {#example}

<CodeGroup>
```json JSON
{
  "commissionPaid": [
    { "alice":   124.50 },
    { "bob":      12.00 },
    { "charlie":  87.34 }
  ]
}
```
</CodeGroup>

## Fouten {#errors}

| Status | Betekenis |
| ------ | ------- |
| `400`  | `fromDate` kan niet worden geparseerd. |
