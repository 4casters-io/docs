De price feed streamt markt-/orderboekupdates als JSON-berichten over een kale WebSocket-verbinding.

<CodeGroup>
```javascript JavaScript
// price_feed_quickstart.js 
const WebSocket = require('ws'); 
const token = process.env.FOURCASTERS_TOKEN; 
 
function connectPriceFeed() { 
  const ws = new 
  WebSocket('wss://streaming-api.4casters.io/price-stream', { 
    headers: { Authorization: token }, 
  }); 
 
  let pingTimer; let lastPong = Date.now(); 
 
  ws.on('open', () => { 
    console.log('price stream connected'); 

    // Optional: narrow the feed to specific games / leagues / sports.
    // Omit this block to receive all market updates (default). 
    ws.send(JSON.stringify({ 
      type: 'subscribe', 
      gameIDs: [], 
      leagueIDs: ['NBA'], 
      sportIDs: [], 
      replace: true, 
    })); 

    pingTimer = setInterval(() => { 
      if (ws.readyState === WebSocket.OPEN) ws.ping(); 
      if (Date.now() - lastPong > 30000) { 
        console.warn('price stream: missed pong >30s, closing'); 
        ws.terminate(); 
      } 
    }, 10000); 
  }); 
 
  ws.on('pong', () => { lastPong = Date.now(); }); 
 
  ws.on('message', (buf) => { 
    try { 
      const msg = JSON.parse(buf.toString()); 
      console.log('price update:', JSON.stringify(msg, null, 2)); 
    } catch { console.log('price update (raw):', buf.toString()); } 
  }); 
 
  ws.on('error', (e) => console.error('price stream error:', e.message)); 
 
  ws.on('close', (code, reason) => { 
    console.log(`price stream closed: ${code} ${reason}`); 
    clearInterval(pingTimer); 
    setTimeout(connectPriceFeed, 1000); 
  }); 
} 
connectPriceFeed();
```
</CodeGroup>

## Ping/Pong

Beide feeds ondersteunen standaard WebSocket-`ping/pong`. Je kunt proactief met een interval `ping()` sturen en `pong` bijhouden om de verbinding op leven te controleren.

## Abonnementen {#subscriptions}

Standaard ontvangt een verbonden client elke marktupdate over alle sporten en competities. Om de stortvloed in te perken stuur je één van de volgende commando's als JSON-tekstframe nadat de socket `open` is. Commando's gelden voor de levensduur van de verbinding.

Een client die nooit een subscribe-commando stuurt, blijft in broadcast-all-modus, zodat bestaande integraties zonder wijzigingen blijven werken.

### Abonneren op gameID, competitie of sport {#subscribe-by-gameid-league-or-sport}

Installeer een filter. `gameIDs` zijn Mongo-ObjectID-hexstrings van 24 tekens; `leagueIDs` zijn korte codes zoals `NBA` / `MLB` / `EPL`; `sportIDs` zijn tokens in kleine letters zoals `basketball` / `baseball` / `soccer`.

<CodeGroup>
```json Replace (aanbevolen)
{
  "type": "subscribe",
  "gameIDs": ["62619dce25e2fb049a71cc2e"],
  "leagueIDs": ["NBA"],
  "sportIDs": [],
  "replace": true
}
```
```json Additief
{
  "type": "subscribe",
  "gameIDs": [],
  "leagueIDs": ["MLB"],
  "sportIDs": [],
  "replace": false
}
```
</CodeGroup>

- `replace: true` wist alle bestaande abonnementen op deze verbinding en installeert de nieuwe lijsten. Zet de verbinding in gefilterde modus.
- `replace: false` voegt de nieuwe sleutels toe aan waar de verbinding al op geabonneerd is.

Je ontvangt een update als zijn `gameID`, `parentGameID`, `league` of `sport` overeenkomt met één van je abonnementen.

### Afmelden {#unsubscribe}

Verwijder specifieke sleutels. De verbinding blijft in haar huidige modus (gefilterd of subscribe-all).

<CodeGroup>
```json JSON
{
  "type": "unsubscribe",
  "gameIDs": [],
  "leagueIDs": ["MLB"],
  "sportIDs": []
}
```
</CodeGroup>

### Op alles abonneren {#subscribe-to-everything}

Expliciete catch-all. Handig als je eerder via `subscribe` hebt gefilterd en de feed weer wilt verbreden zonder opnieuw te verbinden. Wist alle abonnementen per sleutel op de verbinding.

<CodeGroup>
```json JSON
{ "type": "subscribeAll" }
```
</CodeGroup>

### Routeringssemantiek {#routing-semantics}

- Een `gameID`-abonnement ontvangt ook updates voor onderliggende wedstrijden waarvan de `parentGameID` overeenkomt (bijv. F5-MLB-derivaten bereiken abonnees van de parent-wedstrijd).
- Competitie-ids zijn hoofdletterongevoelig — `mlb` en `MLB` zijn gelijkwaardig.
- Sport-ids zijn hoofdletterongevoelig — `baseball` en `Baseball` zijn gelijkwaardig.
- Lege strings in de arrays worden genegeerd.
- `subscribe` met `replace: false` **en** allemaal lege arrays is een no-op (een client met een bug kan zichzelf niet per ongeluk afsluiten van alles door een lege additieve subscribe te sturen).
- `subscribe` met `replace: true` **en** allemaal lege arrays is de legitieme route om "al mijn abonnementen te wissen" — de verbinding komt in gefilterde modus met nul abonnementen en ontvangt niets totdat je je opnieuw abonneert of `subscribeAll` stuurt.

## Berichten {#messages}

Elk bericht op `/price-stream` komt binnen als een 2-tuple `[type, payload]`. Er worden drie berichttypen uitgezonden.

#### `orderUpdate` voor moneyline1x2-markten {#orderupdate-for-moneyline1x2-markets}

- `market` — de uitkomst waar de markt over gaat: een deelnemer-ObjectID-hex (thuis- of uitteam) of de letterlijke string `"draw"`.
- `side` — `"yes"` of `"no"` op die uitkomst.

### `gameUpdate`

Wordt uitgezonden wanneer een wedstrijd wordt aangemaakt of zijn status verandert (markten die openen of sluiten, updates van de starttijd). De payload is de volledig gerenderde wedstrijd.

<CodeGroup>
```json JSON

  "gameUpdate",
  {
    "id": "625ecb5f269b7ff13619ca7c",
    "parentGameID": null,
    "league": "NBA",
    "sport": "basketball",
    "start": "2022-04-22T01:00:00.000Z",
    "ended": false,
    "messageType": "marketOpen",
    "participants": [
      { "id": "607349dc22a237cf46b021fb", "longName": "Dallas Mavericks", "shortName": "DAL", "homeAway": "away", "rotationNumber": "571" },
      { "id": "60747bcde3b0844e56d2e7e8", "longName": "Utah Jazz",        "shortName": "UTA", "homeAway": "home", "rotationNumber": "572" }
    ],
    "awayMoneylines": [],
    "homeMoneylines": [],
    "awaySpreads": {},
    "homeSpreads": {},
    "over": {},
    "under": {},
    "mainHomeSpread": -6.5,
    "mainAwaySpread": 6.5,
```

Bekende `messageType`-waarden: `marketOpen`, `marketClosed`. Beschouw het veld als uitbreidbaar en negeer onbekende waarden.
